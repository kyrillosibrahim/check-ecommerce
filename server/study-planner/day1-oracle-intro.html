أنواع الـ Databases

في نوعين رئيسيين لازم تعرفهم:

🏛️ Relational (علائقية)
  • البيانات في جداول (Tables)
  • صفوف وأعمدة زي Excel
  • الجداول مرتبطة ببعض
  • بتستخدم لغة SQL
  • مثال: Oracle, MySQL, SQL Server
🌐 NoSQL (غير علائقية)
  • البيانات مش في جداول
  • أشكال مختلفة (مستندات/مفاتيح)
  • مرنة ومتغيرة
  • كل نوع ليه لغته
  • مثال: MongoDB, Redis, Neo4j
🏛️

Relational Database - بالتفصيل

البيانات بتتخزن في جداول (Tables) فيها صفوف (Rows) وأعمدة (Columns)، والجداول بتبقى مرتبطة ببعض بـ علاقات (Relations).

مثال عملي: نظام موظفين
📋 جدول الموظفين - EMPLOYEES
EMP_IDNAMESALARYDEPT_IDHIRE_DATE
1أحمد8,000102024-01
2سارة9,500202023-05
3محمد7,000102024-06
🔗 DEPT_ID بيشاور على جدول الأقسام
📋 جدول الأقسام - DEPARTMENTS
DEPT_IDDEPT_NAMELOCATION
10المبيعاتالقاهرة
20التسويقالإسكندرية
العلاقة: DEPT_ID في جدول الموظفين (Foreign Key) بيشاور على DEPT_ID في جدول الأقسام (Primary Key) - كده أحمد ومحمد في قسم المبيعات، وسارة في قسم التسويق
🏆 أشهر قواعد البيانات العلائقية
الاسمالشركةالاستخدامالسعر
Oracle Database Oracle الشركات الكبيرة والبنوك مدفوع + نسخة مجانية
MySQL Oracle المواقع والتطبيقات مجاني
SQL Server Microsoft بيئة Windows مدفوع + نسخة مجانية
PostgreSQL مفتوح المصدر مشاريع متقدمة مجاني

NoSQL Databases - بالتفصيل

📄 Document Database - بيانات على شكل مستندات
JSON Document
{ "name": "أحمد", "salary": 8000, "skills": ["SQL", "Excel", "Python"], "address": { "city": "القاهرة", "street": "شارع التحرير" } }
🏷️ مثال: MongoDB - الأشهر في تطبيقات الويب
🔑 Key-Value Database - مفتاح وقيمة
Key → Value
"user:1001" → "أحمد" "user:1002" → "سارة" "session:abc" → "{ logged_in: true }"
🏷️ مثال: Redis - سريع جداً، بيستخدم للـ Cache
🕸️ Graph Database - شبكة علاقات
Nodes & Relationships
(أحمد) --[صديق]--> (سارة) (أحمد) --[يعمل في]--> (شركة X) (سارة) --[تعرف]--> (محمد)
🏷️ مثال: Neo4j - بيستخدم في Facebook و LinkedIn
⚖️

Relational vs NoSQL

🏛️ Relational (Oracle, MySQL)
  • بيانات منظمة ومحددة الشكل
  • علاقات واضحة بين الجداول
  • أمان ودقة عالية جداً
  • مثالي للبنوك والشركات و ERP
  • بيستخدم لغة SQL موحدة
🌐 NoSQL (MongoDB, Redis)
  • بيانات مرنة ومتغيرة الشكل
  • سرعة عالية في القراءة والكتابة
  • سهولة التوسع أفقياً
  • مثالي للتطبيقات وسوشيال ميديا
  • كل نوع ليه طريقة مختلفة

إيه هي Oracle Database بالتحديد؟

Oracle Database هي نظام إدارة قواعد بيانات علائقية (RDBMS) من شركة Oracle Corporation، وهي الأقوى والأكثر استخداماً في الشركات الكبيرة والبنوك والحكومات حول العالم.
🌟 ليه Oracle مميزة ومختلفة؟
الميزةالتفاصيل
🔒 الأمانأعلى مستوى أمان - عشان كده البنوك بتستخدمها
⚡ الأداءبتتعامل مع ملايين العمليات في الثانية الواحدة
📈 التوسعمن شركة صغيرة لشركة عملاقة بدون مشاكل
🔄 الاستمراريةلو السيرفر وقع البيانات مش هتضيع أبداً
🛠️ الأدواتأدوات إدارة ومراقبة احترافية مدمجة
📚 PL/SQLلغة برمجة خاصة بيها قوية جداً
🏢 مين بيستخدم Oracle؟

🏦 البنوك (الأهلي، QNB، CIB)  •  🏥 المستشفيات  •  📱 شركات الاتصالات (فودافون، اورانچ)  •  🏛️ الحكومات  •  ✈️ شركات الطيران  •  🛒 شركات التجارة الكبيرة

Oracle Architecture - البنية الداخلية

فهم البنية مهم عشان تعرف إيه اللي بيحصل ورا الكواليس لما بتكتب أمر SQL.

البنية العامة لـ Oracle Database
👤 أنت (المستخدم)
SQL Developer / التطبيق / SQL*Plus
⬇
⚙️ Oracle Instance (الذاكرة + العمليات)
🧠 SGA (الذاكرة المشتركة) • Shared Pool
• Buffer Cache
• Redo Log Buffer
👷 Background Processes • DBWR (كتابة البيانات)
• LGWR (كتابة الـ Logs)
• SMON / PMON
⬇
💾 Database Files (الملفات على الهارد)
Data Files (.dbf)  •  Redo Log Files  •  Control Files
📖 شرح كل جزء ببساطة
الجزءالشرحمثال توضيحي
SGA الذاكرة اللي Oracle بتستخدمها عشان تشتغل بسرعة زي الـ RAM - بتحط فيها البيانات اللي بتتعامل معاها دلوقتي
Buffer Cache نسخة من البيانات في الذاكرة بدل ما تروح للهارد كل مرة، بتقرأ من الذاكرة (أسرع 1000x)
Shared Pool بيحفظ أوامر SQL اللي اتنفذت لو كتبت نفس الأمر تاني، مش هيحلله من الأول
DBWR بيكتب البيانات من الذاكرة للهارد زي حد بيحفظ شغلك على الهارد بشكل دوري
LGWR بيسجل كل عملية حصلت زي كاميرا مراقبة - لو حصل مشكلة يقدر يرجع لنقطة معينة
Data Files الملفات اللي البيانات بتتحفظ فيها فعلياً الملفات على الهارد اللي فيها الجداول والبيانات

تثبيت Oracle XE - خطوة بخطوة

📋 المتطلبات

🖥️ Windows 10/11 (64-bit)  •  💾 مساحة 9 GB على الأقل  •  🧠 RAM: 2 GB كحد أدنى (4 GB أفضل)

الخطوة 1: تحميل Oracle XE

1
روح على صفحة التحميل
افتح المتصفح وروح على: oracle.com/database/technologies/xe-downloads.html
2
اختار النسخة
اضغط على Oracle Database 21c Express Edition for Windows x64
3
اعمل حساب Oracle (مجاني)
لو مش عندك حساب، هيطلب تعمل واحد مجاني - سجل بالإيميل وباسورد
4
حمّل الملف
حجم الملف حوالي 1.7 GB - استنى التحميل يخلص

الخطوة 2: التثبيت

1
فك الضغط
كليك يمين على الملف المحمل → Extract Here
2
شغّل كـ Administrator
كليك يمين على setup.exe → Run as Administrator
3
اقبل الشروط
اختار I accept واضغط Next
4
مسار التثبيت
سيبه Default (متغيروش) واضغط Next
5
⚠️ اكتب الباسورد (مهم جداً!)
ده باسورد المستخدم SYS و SYSTEM - احفظه كويس! مثال: Oracle123
6
اضغط Install واستنى
التثبيت بياخد حوالي 10-20 دقيقة - متقفلوش!
7
اضغط Finish
مبروك! Oracle XE اتثبت بنجاح 🎉
⚠️
مهم جداً: احفظ الباسورد اللي كتبته في مكان آمن! لو نسيته هتحتاج تعيد التثبيت من الأول.

الخطوة 3: التأكد إنه شغال

Command Prompt (CMD)
-- افتح CMD واكتب: sqlplus sys/Oracle123@localhost:1521/XEPDB1 as sysdba -- لو ظهرلك: Connected to: Oracle Database 21c Express Edition Release 21.0.0.0.0 -- يبقى مبروك! Oracle شغال ✅
✅
لو ظهرتلك رسالة "Connected to" يبقى كل حاجة تمام ونقدر نكمّل!

تثبيت SQL Developer

SQL Developer هو برنامج مجاني من Oracle بواجهة رسومية سهلة تكتب فيه أوامر SQL وتشوف النتائج بشكل مريح. بدله هتضطر تشتغل من الـ Command Line!
1
روح على صفحة التحميل
افتح: oracle.com/tools/downloads/sqldev-downloads.html
2
حمّل النسخة الصح
اختار Windows 64-bit with JDK included (عشان متحتاجش تنزل Java لوحدها)
3
فك الضغط
كليك يمين → Extract Here → هيطلع مجلد اسمه sqldeveloper
4
شغّله!
افتح المجلد وشغّل sqldeveloper.exe - مفيش تثبيت! بيشتغل مباشرة 🎉
💡
نصيحة: اعمل Shortcut لـ sqldeveloper.exe على الـ Desktop عشان توصله بسهولة كل مرة.
🔌

ربط SQL Developer بـ Oracle XE

1
افتح SQL Developer
شغّل البرنامج واستنى يفتح
2
اعمل Connection جديد
اضغط على علامة + (الأخضر) أو New Connection
3
املأ البيانات التالية:
🔗 بيانات الاتصال
Name: MyOracleXE
Username: sys
Password: Oracle123
Role: SYSDBA
Hostname: localhost
Port: 1521
Service Name: XEPDB1
4
اختبر الاتصال
اضغط Test → لو ظهر Status: Success يبقى تمام!
5
اتصل!
اضغط Connect → هتفتح نافذة SQL Worksheet تكتب فيها أوامر SQL

🎉 أول أمر SQL تكتبه!

SQL Worksheet
SELECT 'مبروك! Oracle شغال!' AS message FROM DUAL; -- اضغط Ctrl+Enter أو زر ▶️ لتشغيل الأمر -- النتيجة: -- ┌─────────────────────┐ -- │ MESSAGE │ -- ├─────────────────────┤ -- │ مبروك! Oracle شغال! │ -- └─────────────────────┘
🎉
مبروك! لو ظهرتلك الرسالة يبقى كل حاجة جاهزة وتقدر تبدأ تتعلم SQL!
📝 ملاحظة عن DUAL

DUAL هو جدول وهمي موجود في Oracle - بنستخدمه لما عايزين نشغل أمر SELECT من غير ما نحتاج جدول حقيقي. زي ما تقول "اطبعلي الحاجة دي وخلاص".
