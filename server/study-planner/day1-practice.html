تجهيز - امسح أي جداول قديمة

SQL - تنظيف
-- لو عندك جداول قديمة بنفس الاسم، امسحها الأول -- (لو مفيش جداول قديمة تجاهل الأخطاء) DROP TABLE employees CASCADE CONSTRAINTS; DROP TABLE departments CASCADE CONSTRAINTS;
💡
نصيحة: افتح SQL Developer وشغّل الأوامر واحد واحد. بعد كل أمر شوف النتيجة قبل ما تكمل. لو حصل خطأ، اقرأ رسالة الخطأ كويس وحاول تفهم السبب قبل ما تبص على الحل.
1
إنشاء الجداول
سهل
▼
🎯 المطلوب: اعمل جدولين:

1. جدول departments:
• dept_id - رقم (4 أرقام) - المفتاح الأساسي
• dept_name - نص (50 حرف) - مطلوب وفريد
• location - نص (100 حرف)
• manager_name - نص (50 حرف)

2. جدول employees:
• emp_id - رقم (6 أرقام) - المفتاح الأساسي
• first_name - نص (50) - مطلوب
• last_name - نص (50) - مطلوب
• email - نص (100) - فريد
• phone - نص (20)
• job_title - نص (50)
• salary - رقم (8,2) - لازم أكبر من 0
• hire_date - تاريخ - افتراضي تاريخ اليوم
• dept_id - رقم (4) - مرتبط بجدول departments
💡 تلميح (اضغط للكشف)
• لازم تعمل جدول departments الأول (عشان employees مرتبط بيه)
• استخدم PRIMARY KEY, NOT NULL, UNIQUE, CHECK, DEFAULT, REFERENCES
• الهاتف VARCHAR2 مش NUMBER (بيبدأ بـ 0)
SQL - الحل
-- 1. جدول الأقسام (لازم يتعمل الأول!) CREATE TABLE departments ( dept_id NUMBER(4) PRIMARY KEY, dept_name VARCHAR2(50) NOT NULL UNIQUE, location VARCHAR2(100), manager_name VARCHAR2(50) ); -- 2. جدول الموظفين CREATE TABLE employees ( emp_id NUMBER(6) PRIMARY KEY, first_name VARCHAR2(50) NOT NULL, last_name VARCHAR2(50) NOT NULL, email VARCHAR2(100) UNIQUE, phone VARCHAR2(20), job_title VARCHAR2(50), salary NUMBER(8,2) CHECK (salary > 0), hire_date DATE DEFAULT SYSDATE, dept_id NUMBER(4) REFERENCES departments(dept_id) );

AND و OR - شروط مركبة
متوسط
▼
🎯 اكتب:

6A) الموظفين في التطوير (10) ومرتبهم فوق 10000
6B) الموظفين في المبيعات (20) أو التسويق (30)
6C) الموظفين اللي مش في المحاسبة (50) ومرتبهم أكبر من 9000
6D) الموظفين في (التطوير أو التسويق) ومرتبهم بين 8000 و 15000
SQL - الحل
-- 6A SELECT first_name, salary FROM employees WHERE dept_id = 10 AND salary > 10000; -- 6B SELECT first_name, dept_id FROM employees WHERE dept_id = 20 OR dept_id = 30; -- 6C SELECT first_name, salary, dept_id FROM employees WHERE dept_id != 50 AND salary > 9000; -- 6D (لاحظ الأقواس!) SELECT first_name, salary, dept_id FROM employees WHERE (dept_id = 10 OR dept_id = 30) AND salary BETWEEN 8000 AND 15000;

ORDER BY - الترتيب
متوسط
▼
🎯 اكتب:

9A) كل الموظفين مرتبين بالمرتب من الأعلى للأقل
9B) كل الموظفين مرتبين بتاريخ التعيين (الأقدم الأول)
9C) موظفين المبيعات (20) مرتبين بالمرتب تنازلياً
9D) كل الموظفين مرتبين بالقسم ثم بالمرتب تنازلياً جوا كل قسم
SQL - الحل
-- 9A SELECT first_name, salary FROM employees ORDER BY salary DESC; -- 9B SELECT first_name, hire_date FROM employees ORDER BY hire_date ASC; -- 9C SELECT first_name, salary FROM employees WHERE dept_id = 20 ORDER BY salary DESC; -- 9D SELECT first_name, dept_id, salary FROM employees ORDER BY dept_id ASC, salary DESC;

DISTINCT - القيم الفريدة
متوسط
▼
🎯 اكتب:

10A) كل المسميات الوظيفية الموجودة (بدون تكرار)
10B) كل أرقام الأقسام اللي فيها موظفين (بدون تكرار)
10C) كل التوليفات الفريدة من (القسم + المسمى الوظيفي)
SQL - الحل
-- 10A SELECT DISTINCT job_title FROM employees ORDER BY job_title; -- 10B SELECT DISTINCT dept_id FROM employees ORDER BY dept_id; -- 10C SELECT DISTINCT dept_id, job_title FROM employees ORDER BY dept_id;
11
حسابات وتجميعات متقدمة
صعب
▼
🎯 اكتب:

11A) الاسم الكامل + المرتب الشهري + المرتب السنوي + الضرائب (14%) لموظفين التطوير
11B) الموظفين اللي مرتبهم السنوي (×12) أكبر من 120000 مرتبين تنازلياً
11C) اظهر جملة لكل موظف بالشكل: "أحمد محمود يعمل كـ مطور أول بمرتب 15000"
SQL - الحل
-- 11A SELECT first_name || ' ' || last_name AS "الاسم", salary AS "الشهري", salary * 12 AS "السنوي", salary * 0.14 AS "الضرائب", salary - (salary * 0.14) AS "الصافي" FROM employees WHERE dept_id = 10; -- 11B SELECT first_name, salary, salary * 12 AS "السنوي" FROM employees WHERE salary * 12 > 120000 ORDER BY salary DESC; -- 11C SELECT first_name || ' ' || last_name || ' يعمل كـ ' || job_title || ' بمرتب ' || salary AS "معلومات الموظف" FROM employees;
12
🔥 التحدي النهائي - تقرير شامل
صعب
▼
🎯 المدير طلب التقارير دي قبل نهاية اليوم:

12A) أعلى 5 مرتبات في الشركة مع الاسم الكامل والقسم
12B) الموظفين اللي اتعينوا في 2023 في (المبيعات أو التسويق) ومرتبهم أقل من 10000
12C) كل الموظفين ماعدا المديرين (job_title مفيهاش "مدير")، مرتبين بالقسم ثم الاسم
12D) تقرير شامل فيه: الاسم الكامل، المسمى، المرتب الشهري والسنوي والصافي بعد الضرائب، مرتبين من أعلى صافي
SQL - الحل
-- 12A SELECT first_name || ' ' || last_name AS "الاسم", salary, dept_id FROM employees ORDER BY salary DESC FETCH FIRST 5 ROWS ONLY; -- 12B SELECT first_name, hire_date, dept_id, salary FROM employees WHERE hire_date BETWEEN TO_DATE('2023-01-01','YYYY-MM-DD') AND TO_DATE('2023-12-31','YYYY-MM-DD') AND dept_id IN (20, 30) AND salary < 10000; -- 12C SELECT first_name, job_title, dept_id FROM employees WHERE job_title NOT LIKE '%مدير%' ORDER BY dept_id, first_name; -- 12D - التقرير الشامل 🔥 SELECT first_name || ' ' || last_name AS "الاسم الكامل", job_title AS "المسمى الوظيفي", salary AS "الشهري", salary * 12 AS "السنوي", salary * 0.14 AS "الضرائب", salary - (salary * 0.14) AS "الصافي" FROM employees ORDER BY (salary - (salary * 0.14)) DESC;
