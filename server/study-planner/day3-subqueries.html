BETWEEN - البحث في نطاق

BETWEEN بيفلتر القيم اللي بين قيمتين (شاملة الحدين). بديل مختصر لـ >= AND <=

📐 الصيغة
WHERE column BETWEEN low_value AND high_value; -- يساوي: WHERE column >= low_value AND column <= high_value;
أمثلة BETWEEN
-- المرتبات بين 8000 و 16000 SELECT first_name, salary FROM employees WHERE salary BETWEEN 8000 AND 16000; -- الموظفين اللي اتعينوا في 2022 SELECT first_name, hire_date FROM employees WHERE hire_date BETWEEN DATE '2022-01-01' AND DATE '2022-12-31'; -- NOT BETWEEN - خارج النطاق SELECT first_name, salary FROM employees WHERE salary NOT BETWEEN 8000 AND 16000;
⚠️ BETWEEN شامل الحدين! يعني BETWEEN 8000 AND 16000 بيشمل 8000 و 16000 نفسهم.
📋

IN - البحث في قائمة

IN بيفلتر القيم اللي موجودة في قائمة محددة. بديل مختصر لعدة OR.

IN بدل OR OR OR
-- ❌ طريقة طويلة بـ OR SELECT * FROM employees WHERE dept_id = 10 OR dept_id = 20 OR dept_id = 30; -- ✅ طريقة مختصرة بـ IN SELECT * FROM employees WHERE dept_id IN (10, 20, 30); -- بيشتغل مع النصوص كمان SELECT * FROM departments WHERE location IN ('القاهرة', 'الإسكندرية'); -- NOT IN - اللي مش في القائمة SELECT first_name, dept_id FROM employees WHERE dept_id NOT IN (10, 20);
🚨 تحذير: NOT IN مع NULL بيدي نتيجة غلط! لو القائمة فيها NULL مش هيرجع أي حاجة. استخدم NOT EXISTS بدلها.

LIKE - البحث بالنمط

LIKE بيبحث عن نمط في النصوص. بيستخدم رمزين خاصين (Wildcards):

%
أي عدد من الحروف (صفر أو أكتر)
'%أحمد%' → أي حاجة فيها أحمد
_
حرف واحد بالظبط
'_مر' → عمر، ثمر (3 حروف)
أمثلة LIKE الأساسية
-- الأسماء اللي بتبدأ بـ "م" SELECT first_name FROM employees WHERE first_name LIKE 'م%'; -- النتيجة: محمد، منى -- الأسماء اللي بتنتهي بـ "ة" SELECT first_name FROM employees WHERE first_name LIKE '%ة'; -- النتيجة: فاطمة، سارة (لو بتنتهي بتاء مربوطة) -- الإيميلات اللي فيها نقطة قبل @ SELECT first_name, email FROM employees WHERE email LIKE '%.%@%'; -- النتيجة: moh.hassan@star.com -- الأسماء اللي 3 حروف بالظبط SELECT first_name FROM employees WHERE first_name LIKE '___'; -- 3 underscores = 3 حروف
🔍

LIKE - أمثلة متقدمة

أنماط متقدمة
-- الإيميلات اللي فيها underscore (_) حرفياً -- لازم نستخدم ESCAPE SELECT email FROM employees WHERE email LIKE '%\_%' ESCAPE '\'; -- النتيجة: omar_k@, yousef_ib@, mona_abd@, reem_h@ -- NOT LIKE - اللي مش بيبدأ بـ "م" SELECT first_name FROM employees WHERE first_name NOT LIKE 'م%'; -- دمج LIKE مع AND SELECT first_name, email, salary FROM employees WHERE email LIKE '%@star.com' AND salary BETWEEN 10000 AND 20000;
📊 ملخص أنماط LIKE الشائعة
النمطالمعنىمثال
'أ%'بيبدأ بـ "أ"أحمد
'%د'بينتهي بـ "د"أحمد، محمد
'%حم%'فيه "حم" في أي مكانأحمد، محمد، محمود
'___'3 حروف بالظبطنور، عمر، ريم
'_ا%'تاني حرف "ا"سارة، فاطمة، خالد

ما هي الـ Subquery؟

الـ Subquery (أو Inner Query) هي Query جوه Query تانية. الـ Query الداخلية بتتنفذ الأول ونتيجتها بتُستخدم في الـ Query الخارجية.

زي ما بتحل معادلة رياضية: بتحل اللي جوه الأقواس الأول.

🎯 مثال: "عايز الموظفين اللي مرتبهم أعلى من المتوسط" - لازم تحسب المتوسط الأول (Subquery) وبعدين تقارن بيه!
📍 أماكن استخدام Subquery
  • في WHERE - الأكثر شيوعاً
  • في FROM - كأنها جدول مؤقت (Inline View)
  • في SELECT - كأنها عمود محسوب
  • في HAVING - فلترة المجموعات
🎯

Subquery في WHERE

الموظفين اللي مرتبهم أعلى من المتوسط
Single-row Subquery
-- الموظفين اللي مرتبهم فوق المتوسط SELECT first_name, salary FROM employees WHERE salary > (SELECT AVG(salary) FROM employees); -- الـ Subquery بترجع قيمة واحدة (المتوسط) -- الموظف اللي عنده أعلى مرتب SELECT first_name, salary FROM employees WHERE salary = (SELECT MAX(salary) FROM employees); -- النتيجة: فاطمة - 22000 -- الموظفين في نفس قسم سارة SELECT first_name, dept_id FROM employees WHERE dept_id = ( SELECT dept_id FROM employees WHERE first_name = 'سارة' );
💡 Single-row Subquery بترجع قيمة واحدة بس. بنستخدم معاها =, >, <, >=, <=, !=
📋

Subquery مع IN

لما الـ Subquery بترجع أكتر من قيمة، مش هنقدر نستخدم = ! لازم نستخدم IN.

Multi-row Subquery مع IN
-- الموظفين في الأقسام اللي في القاهرة SELECT first_name, salary, dept_id FROM employees WHERE dept_id IN ( SELECT dept_id FROM departments WHERE location = 'القاهرة' ); -- الـ Subquery بترجع (10, 30) = أقسام القاهرة -- الأقسام اللي فيها موظفين مرتبهم فوق 15000 SELECT dept_name FROM departments WHERE dept_id IN ( SELECT dept_id FROM employees WHERE salary > 15000 ); -- الأقسام اللي مفيش فيها أي موظف SELECT dept_name FROM departments WHERE dept_id NOT IN ( SELECT dept_id FROM employees WHERE dept_id IS NOT NULL -- مهم! عشان NOT IN مع NULL );
📊

Subquery في FROM (Inline View)

ممكن تحط Subquery في FROM كأنها جدول مؤقت. لازم تديها Alias.

Inline View
-- إحصائيات الأقسام + فلترة على المتوسط SELECT dept_stats.dept_id, dept_stats.emp_count, dept_stats.avg_sal FROM ( SELECT dept_id, COUNT(*) AS emp_count, ROUND(AVG(salary)) AS avg_sal FROM employees WHERE dept_id IS NOT NULL GROUP BY dept_id ) dept_stats -- Alias إجباري! WHERE dept_stats.avg_sal > 10000;
💡 Inline View مفيدة لما عايز تفلتر على نتيجة GROUP BY بشكل أكتر من HAVING.

Subquery في SELECT (Scalar)

عمود محسوب بـ Subquery
-- كل موظف ومعاه متوسط مرتب الشركة والفرق SELECT first_name, salary, (SELECT ROUND(AVG(salary)) FROM employees) AS company_avg, salary - (SELECT ROUND(AVG(salary)) FROM employees) AS diff_from_avg FROM employees ORDER BY diff_from_avg DESC;

EXISTS و NOT EXISTS

EXISTS بيرجع TRUE لو الـ Subquery رجعت أي صف (حتى لو واحد). مش مهم إيه القيم - المهم هل فيه نتيجة ولا لأ.

EXISTS - الأقسام اللي فيها موظفين
-- الأقسام اللي فيها موظف واحد على الأقل SELECT d.dept_name FROM departments d WHERE EXISTS ( SELECT 1 FROM employees e WHERE e.dept_id = d.dept_id );
NOT EXISTS - الأقسام الفاضية
-- الأقسام اللي مفيهاش أي موظف SELECT d.dept_name FROM departments d WHERE NOT EXISTS ( SELECT 1 FROM employees e WHERE e.dept_id = d.dept_id ); -- النتيجة: التسويق (لو مفيش موظفين فيه) -- الموظفين اللي مش مديرين (محدش بيتبع لهم) SELECT e.first_name FROM employees e WHERE NOT EXISTS ( SELECT 1 FROM employees sub WHERE sub.manager_id = e.emp_id );
💡 SELECT 1 جوه EXISTS - مش مهم نكتب أي عمود لأن EXISTS بيشيك بس هل فيه صفوف ولا لأ.
⚔️

IN vs EXISTS - إيه الفرق؟

📋 IN

بيقارن قيمة بقائمة

أسرع لما الـ Subquery صغيرة

مشكلة مع NOT IN + NULL

أبسط وأسهل في القراءة

✅ EXISTS

بيشيك هل فيه نتيجة

أسرع لما الجدول الخارجي صغير

بيتعامل صح مع NULL

أقوى مع Correlated Subqueries

🎯 قاعدة عملية: استخدم IN لو القائمة قصيرة وواضحة. استخدم EXISTS لو بتربط بالجدول الخارجي أو عندك NULLs.
🔄

Correlated Subquery - المرتبطة

Subquery عادية بتتنفذ مرة واحدة. بس Correlated Subquery بتتنفذ مرة لكل صف في الـ Query الخارجية لأنها بتعتمد على قيم من الصف الحالي.

الموظفين اللي مرتبهم أعلى من متوسط قسمهم
SELECT e.first_name, e.salary, e.dept_id FROM employees e WHERE e.salary > ( SELECT AVG(e2.salary) FROM employees e2 WHERE e2.dept_id = e.dept_id -- مرتبطة بالصف الخارجي! ) ORDER BY e.dept_id;
⚠️ Correlated Subquery ممكن تكون بطيئة لأنها بتتنفذ لكل صف. لو الأداء مهم، حوّلها لـ JOIN.
نفس النتيجة بـ JOIN (أسرع)
SELECT e.first_name, e.salary, e.dept_id FROM employees e INNER JOIN ( SELECT dept_id, AVG(salary) AS avg_sal FROM employees GROUP BY dept_id ) dept_avg ON e.dept_id = dept_avg.dept_id WHERE e.salary > dept_avg.avg_sal;

تمارين عملية

سهل 1: BETWEEN + LIKE◀

اعرض الموظفين اللي مرتبهم بين 7000 و 15000 واسمهم بيبدأ بـ "أ" أو "م".

SELECT first_name, salary FROM employees WHERE salary BETWEEN 7000 AND 15000 AND (first_name LIKE 'أ%' OR first_name LIKE 'م%');
سهل 2: IN◀

اعرض الموظفين اللي في قسم المبيعات (10) أو التقنية (20) أو الموارد البشرية (30).

SELECT first_name, salary, dept_id FROM employees WHERE dept_id IN (10, 20, 30) ORDER BY dept_id;
سهل 3: LIKE◀

اعرض الموظفين اللي الإيميل بتاعهم فيه underscore (_).

SELECT first_name, email FROM employees WHERE email LIKE '%\_%' ESCAPE '\';
متوسط 4: Subquery - فوق المتوسط◀

اعرض الموظفين اللي مرتبهم أعلى من متوسط الشركة. اعرض اسمهم ومرتبهم والمتوسط والفرق.

SELECT first_name, salary, (SELECT ROUND(AVG(salary)) FROM employees) AS avg_sal, salary - (SELECT ROUND(AVG(salary)) FROM employees) AS diff FROM employees WHERE salary > (SELECT AVG(salary) FROM employees) ORDER BY salary DESC;
متوسط 5: Subquery مع IN◀

اعرض الموظفين اللي شغالين في أقسام الإسكندرية (بدون ما تكتب رقم القسم مباشرة).

SELECT first_name, salary FROM employees WHERE dept_id IN ( SELECT dept_id FROM departments WHERE location = 'الإسكندرية' );
متوسط 6: NOT EXISTS◀

اعرض الأقسام اللي مفيهاش أي موظف باستخدام NOT EXISTS.

SELECT d.dept_name, d.location FROM departments d WHERE NOT EXISTS ( SELECT 1 FROM employees e WHERE e.dept_id = d.dept_id );
صعب 7: Correlated Subquery◀

اعرض الموظفين اللي مرتبهم أعلى من متوسط قسمهم. اعرض الاسم والمرتب ومتوسط القسم.

SELECT e.first_name, e.salary, e.dept_id, (SELECT ROUND(AVG(e2.salary)) FROM employees e2 WHERE e2.dept_id = e.dept_id) AS dept_avg FROM employees e WHERE e.salary > ( SELECT AVG(e3.salary) FROM employees e3 WHERE e3.dept_id = e.dept_id ) ORDER BY e.dept_id;
صعب 8: Subquery في FROM◀

اعرض الأقسام اللي عدد موظفينها أكبر من 2 ومتوسط مرتبها فوق 8000. استخدم Inline View.

SELECT ds.dept_id, ds.emp_count, ds.avg_sal FROM ( SELECT dept_id, COUNT(*) AS emp_count, ROUND(AVG(salary)) AS avg_sal FROM employees WHERE dept_id IS NOT NULL GROUP BY dept_id ) ds WHERE ds.emp_count > 2 AND ds.avg_sal > 8000;
صعب 9: كل حاجة مع بعض◀

اعرض الموظفين اللي (1) مرتبهم بين 8000 و 20000 و (2) في أقسام القاهرة و (3) اسمهم مش بيبدأ بـ "ي". استخدم BETWEEN + IN مع Subquery + NOT LIKE.

SELECT first_name, salary, dept_id FROM employees WHERE salary BETWEEN 8000 AND 20000 AND dept_id IN ( SELECT dept_id FROM departments WHERE location = 'القاهرة' ) AND first_name NOT LIKE 'ي%' ORDER BY salary DESC;
تحدي 10: التحدي النهائي◀

اعرض لكل قسم: اسمه، عدد موظفينه، عدد الموظفين اللي مرتبهم فوق متوسط الشركة، أعلى مرتب فيه. بس الأقسام اللي فيها موظف واحد على الأقل فوق المتوسط. رتب حسب عدد الموظفين فوق المتوسط تنازلياً.

SELECT d.dept_name, COUNT(e.emp_id) AS total_emp, COUNT(CASE WHEN e.salary > ( SELECT AVG(salary) FROM employees ) THEN 1 END) AS above_avg_count, MAX(e.salary) AS max_salary FROM departments d INNER JOIN employees e ON d.dept_id = e.dept_id GROUP BY d.dept_name HAVING COUNT(CASE WHEN e.salary > ( SELECT AVG(salary) FROM employees ) THEN 1 END) >= 1 ORDER BY above_avg_count DESC;
