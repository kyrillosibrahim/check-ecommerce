Cursors و Exception Handling

هتتعلم إزاي تقرأ بيانات كتير صف بصف بالـ Cursors وتتعامل مع الأخطاء بذكاء بالـ Exception Handling!

الجزء الأول - CURSORS

ليه محتاج Cursors؟

📋

تشبيه: قائمة الأسماء!

تخيل عندك قائمة فيها 100 اسم. SELECT INTO بتجيب اسم واحد بس. لو عايز تقرأ القائمة كلها واحد واحد وتعمل حاجة مع كل اسم، محتاج Cursor! الـ Cursor هو "إصبعك" اللي بيمشي على كل صف في النتيجة.

🚨 المشكلة: SELECT INTO بتجيب صف واحد بس. لو الـ Query رجّعت أكتر من صف → TOO_MANY_ROWS error. لو مرجعتش حاجة → NO_DATA_FOUND. الـ Cursor بيحل المشكلة دي!
ضمني

Implicit Cursor

Oracle بيعمل Implicit Cursor تلقائي مع كل SQL statement (INSERT, UPDATE, DELETE). تقدر تستخدم attributes عشان تعرف إيه اللي حصل:

Implicit Cursor Attributes:

الـ Attributeالوصفالنوع
SQL%FOUNDTRUE لو آخر statement أثّر على صف واحد على الأقلBOOLEAN
SQL%NOTFOUNDTRUE لو مأثرش على أي صفBOOLEAN
SQL%ROWCOUNTعدد الصفوف اللي اتأثرتNUMBER
SQL%ISOPENدايماً FALSE (Oracle بيقفله تلقائي)BOOLEAN
PL/SQL - Implicit Cursor 
BEGIN
    UPDATE employees
    SET salary = salary * 1.10
    WHERE department_id = 20;

    IF SQL%FOUND THEN
        DBMS_OUTPUT.PUT_LINE('تم تحديث ' || SQL%ROWCOUNT || ' موظف');
    ELSE
        DBMS_OUTPUT.PUT_LINE('مفيش موظفين في القسم ده!');
    END IF;

    COMMIT;
END;
/

Explicit Cursor

الـ Explicit Cursor بتعرّفه بنفسك عشان تقرأ نتيجة SELECT صف بصف:

1. تعريفDECLARE
→
2. فتحOPEN
→
3. قراءةFETCH
→
4. قفلCLOSE
PL/SQL - Explicit Cursor (الطريقة الكاملة) 
DECLARE
    -- 1. تعريف الـ Cursor
    CURSOR c_employees IS
        SELECT employee_id, first_name, salary
        FROM employees
        WHERE department_id = 20;

    v_id     employees.employee_id%TYPE;
    v_name   employees.first_name%TYPE;
    v_salary employees.salary%TYPE;
BEGIN
    -- 2. فتح الـ Cursor
    OPEN c_employees;

    -- 3. قراءة صف بصف
    LOOP
        FETCH c_employees INTO v_id, v_name, v_salary;
        EXIT WHEN c_employees%NOTFOUND;  -- لما يخلص الصفوف

        DBMS_OUTPUT.PUT_LINE(v_id || ' - ' || v_name || ' - ' || v_salary);
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('إجمالي: ' || c_employees%ROWCOUNT || ' موظف');

    -- 4. قفل الـ Cursor
    CLOSE c_employees;
END;
/

Explicit Cursor Attributes:

الـ Attributeالوصف
cursor%FOUNDTRUE لو آخر FETCH جاب صف
cursor%NOTFOUNDTRUE لو آخر FETCH مجابش صف (خلصت البيانات)
cursor%ROWCOUNTعدد الصفوف اللي اتقرأت لحد دلوقتي
cursor%ISOPENTRUE لو الـ Cursor مفتوح
الأسهل

Cursor FOR LOOP (الطريقة المختصرة)

دي أسهل وأفضل طريقة! مش محتاج OPEN ولا FETCH ولا CLOSE - كل ده بيحصل تلقائي:

PL/SQL - Cursor FOR LOOP 
DECLARE
    CURSOR c_employees IS
        SELECT employee_id, first_name, salary, department_id
        FROM employees
        WHERE salary > 5000
        ORDER BY salary DESC;
BEGIN
    FOR emp IN c_employees LOOP
        DBMS_OUTPUT.PUT_LINE(
            emp.employee_id || ' | ' ||
            emp.first_name || ' | ' ||
            emp.salary
        );
    END LOOP;  -- CLOSE تلقائي!
END;
/
✅ ميزات Cursor FOR LOOP:
  • مش محتاج OPEN / FETCH / CLOSE
  • مش محتاج تعرّف متغيرات منفصلة - emp بياخد الصف كامل
  • مش محتاج EXIT WHEN - بيقف تلقائي لما البيانات تخلص
  • أقصر وأنظف كود!

Cursor FOR LOOP بدون تعريف مسبق

PL/SQL - Inline Cursor 
-- أقصر طريقة! الـ SELECT مباشرة في الـ FOR
BEGIN
    FOR emp IN (
        SELECT first_name, salary
        FROM employees
        WHERE department_id = 30
    ) LOOP
        DBMS_OUTPUT.PUT_LINE(emp.first_name || ': ' || emp.salary);
    END LOOP;
END;
/
مرن

Cursor مع Parameters

PL/SQL - Parameterized Cursor 
DECLARE
    -- Cursor يقبل parameter
    CURSOR c_dept_emps(p_dept_id NUMBER) IS
        SELECT first_name, salary
        FROM employees
        WHERE department_id = p_dept_id
        ORDER BY salary DESC;
BEGIN
    -- استخدمه لقسم 10
    DBMS_OUTPUT.PUT_LINE('=== قسم 10 ===');
    FOR emp IN c_dept_emps(10) LOOP
        DBMS_OUTPUT.PUT_LINE(emp.first_name || ': ' || emp.salary);
    END LOOP;

    -- نفس الـ Cursor لقسم 20
    DBMS_OUTPUT.PUT_LINE('=== قسم 20 ===');
    FOR emp IN c_dept_emps(20) LOOP
        DBMS_OUTPUT.PUT_LINE(emp.first_name || ': ' || emp.salary);
    END LOOP;
END;
/
تحديث

Cursor مع UPDATE (WHERE CURRENT OF)

تقدر تعمل UPDATE على الصف اللي الـ Cursor واقف عليه:

PL/SQL - Cursor FOR UPDATE 
DECLARE
    CURSOR c_low_salary IS
        SELECT employee_id, first_name, salary
        FROM employees
        WHERE salary < 5000
        FOR UPDATE;  -- مهم! يقفل الصفوف

    v_count NUMBER := 0;
BEGIN
    FOR emp IN c_low_salary LOOP
        UPDATE employees
        SET salary = salary * 1.15  -- زيادة 15%
        WHERE CURRENT OF c_low_salary;

        v_count := v_count + 1;
        DBMS_OUTPUT.PUT_LINE(emp.first_name || ': ' ||
            emp.salary || ' → ' || ROUND(emp.salary * 1.15));
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('تم تحديث ' || v_count || ' موظف');
    COMMIT;
END;
/
⚠️ FOR UPDATE: بيقفل الصفوف (Lock) عشان محدش تاني يعدلها وأنت بتقرأ. لازم تعمل COMMIT أو ROLLBACK عشان تفك القفل.
متقدم

REF CURSOR (Cursor ديناميكي)

الـ REF CURSOR بيخليك تحدد الـ Query وقت التشغيل مش وقت التعريف:

PL/SQL - REF CURSOR 
DECLARE
    -- تعريف REF CURSOR type
    TYPE t_emp_cursor IS REF CURSOR;
    c_emps t_emp_cursor;

    v_name   employees.first_name%TYPE;
    v_salary employees.salary%TYPE;
    v_choice NUMBER := 1;
BEGIN
    -- فتح الـ Cursor بـ query مختلفة حسب الاختيار
    IF v_choice = 1 THEN
        OPEN c_emps FOR
            SELECT first_name, salary FROM employees
            WHERE salary > 10000;
    ELSE
        OPEN c_emps FOR
            SELECT first_name, salary FROM employees
            WHERE salary <= 10000;
    END IF;

    LOOP
        FETCH c_emps INTO v_name, v_salary;
        EXIT WHEN c_emps%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE(v_name || ': ' || v_salary);
    END LOOP;

    CLOSE c_emps;
END;
/
ملخص: الـ Cursor العادي = الـ Query ثابتة وقت التعريف. الـ REF CURSOR = الـ Query ممكن تتغير وقت التشغيل. استخدم العادي في 90% من الحالات.

تشبيه: حزام الأمان!

Exception Handling زي حزام الأمان في العربية. مش بتمنع الحادثة، لكن لو حصلت بتحميك! بدل ما البرنامج يقع ويوقف، بتمسك الخطأ وتتعامل معاه.

PL/SQL - Exception Structure 
BEGIN
    -- الكود العادي
    statements;

EXCEPTION
    WHEN exception_name1 THEN
        -- تعامل مع الخطأ الأول
    WHEN exception_name2 THEN
        -- تعامل مع الخطأ التاني
    WHEN OTHERS THEN
        -- أي خطأ تاني (catch-all)
END;
/

الأشهر

NO_DATA_FOUND بالتفصيل

ده أشهر Exception هتقابله! بيحصل لما SELECT INTO مترجعش أي نتيجة:

PL/SQL - NO_DATA_FOUND 
DECLARE
    v_name   employees.first_name%TYPE;
    v_salary employees.salary%TYPE;
BEGIN
    SELECT first_name, salary
    INTO v_name, v_salary
    FROM employees
    WHERE employee_id = 9999;  -- مش موجود!

    DBMS_OUTPUT.PUT_LINE('الموظف: ' || v_name);

EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('الموظف مش موجود في النظام!');
        DBMS_OUTPUT.PUT_LINE('الكود: ' || SQLCODE);
        DBMS_OUTPUT.PUT_LINE('الرسالة: ' || SQLERRM);
END;
/
💡 SQLCODE و SQLERRM:
  • SQLCODE = رقم الخطأ (مثلاً -1403)
  • SQLERRM = رسالة الخطأ كاملة

التعامل مع أكتر من Exception

PL/SQL - Multiple Exceptions 
DECLARE
    v_name   employees.first_name%TYPE;
    v_salary employees.salary%TYPE;
    v_result NUMBER;
BEGIN
    SELECT first_name, salary
    INTO v_name, v_salary
    FROM employees
    WHERE department_id = 20;  -- ممكن يرجع أكتر من صف!

    v_result := v_salary / 0;  -- قسمة على صفر!

EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('مفيش بيانات!');
    WHEN TOO_MANY_ROWS THEN
        DBMS_OUTPUT.PUT_LINE('أكتر من موظف! استخدم Cursor.');
    WHEN ZERO_DIVIDE THEN
        DBMS_OUTPUT.PUT_LINE('مينفعش تقسم على صفر!');
END;
/
شائع

TOO_MANY_ROWS

PL/SQL - TOO_MANY_ROWS 
DECLARE
    v_name employees.first_name%TYPE;
BEGIN
    -- ده هيفشل لو القسم فيه أكتر من موظف
    SELECT first_name INTO v_name
    FROM employees
    WHERE department_id = 20;

EXCEPTION
    WHEN TOO_MANY_ROWS THEN
        DBMS_OUTPUT.PUT_LINE('القسم فيه أكتر من موظف!');
        DBMS_OUTPUT.PUT_LINE('استخدم Cursor بدل SELECT INTO');

        -- الحل: استخدم Cursor!
        FOR emp IN (SELECT first_name FROM employees
                    WHERE department_id = 20) LOOP
            DBMS_OUTPUT.PUT_LINE('  - ' || emp.first_name);
        END LOOP;
END;
/
شامل

WHEN OTHERS (Catch-All)

PL/SQL - WHEN OTHERS 
DECLARE
    v_result NUMBER;
BEGIN
    v_result := 100 / 0;

EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('مفيش بيانات');
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('حصل خطأ غير متوقع!');
        DBMS_OUTPUT.PUT_LINE('الكود: ' || SQLCODE);
        DBMS_OUTPUT.PUT_LINE('التفاصيل: ' || SQLERRM);
        ROLLBACK;
END;
/
🚨 قاعدة مهمة: WHEN OTHERS لازم تكون آخر WHEN في الـ EXCEPTION block. لو حطيتها الأول هتمسك كل الأخطاء ومش هتوصل للباقي!
مخصص

User-Defined Exceptions

تقدر تعمل Exceptions خاصة بيك عشان تتعامل مع حالات معينة في البزنس:

PL/SQL - Custom Exception 
DECLARE
    -- تعريف Exception خاص
    e_salary_too_high EXCEPTION;
    e_salary_too_low  EXCEPTION;

    v_salary NUMBER := 50000;
BEGIN
    IF v_salary > 30000 THEN
        RAISE e_salary_too_high;  -- إطلاق الـ Exception يدوياً!
    ELSIF v_salary < 3000 THEN
        RAISE e_salary_too_low;
    ELSE
        DBMS_OUTPUT.PUT_LINE('المرتب مقبول: ' || v_salary);
    END IF;

EXCEPTION
    WHEN e_salary_too_high THEN
        DBMS_OUTPUT.PUT_LINE('خطأ: المرتب ' || v_salary || ' عالي جداً! الحد الأقصى 30000');
    WHEN e_salary_too_low THEN
        DBMS_OUTPUT.PUT_LINE('خطأ: المرتب ' || v_salary || ' قليل جداً! الحد الأدنى 3000');
END;
/
احترافي

RAISE_APPLICATION_ERROR

بتسمح لك تعمل error message مخصصة برقم خطأ من -20000 لـ -20999:

PL/SQL - RAISE_APPLICATION_ERROR 
CREATE OR REPLACE PROCEDURE update_salary(
    p_emp_id  IN NUMBER,
    p_new_sal IN NUMBER
)
IS
    v_old_sal employees.salary%TYPE;
BEGIN
    SELECT salary INTO v_old_sal
    FROM employees WHERE employee_id = p_emp_id;

    -- Business Rules
    IF p_new_sal < 3000 THEN
        RAISE_APPLICATION_ERROR(-20001,
            'المرتب لازم يكون على الأقل 3000. القيمة المدخلة: ' || p_new_sal);
    END IF;

    IF p_new_sal > v_old_sal * 2 THEN
        RAISE_APPLICATION_ERROR(-20002,
            'الزيادة مش ممكن تكون أكتر من الضعف! القديم: ' || v_old_sal);
    END IF;

    UPDATE employees SET salary = p_new_sal
    WHERE employee_id = p_emp_id;

    DBMS_OUTPUT.PUT_LINE('تم التحديث: ' || v_old_sal || ' → ' || p_new_sal);
    COMMIT;

EXCEPTION
    WHEN NO_DATA_FOUND THEN
        RAISE_APPLICATION_ERROR(-20003,
            'الموظف رقم ' || p_emp_id || ' مش موجود!');
END;
/
💡 الفرق بين RAISE و RAISE_APPLICATION_ERROR:
  • RAISE: بيطلق Exception بدون رسالة مخصصة (بيستخدم الرسالة الافتراضية)
  • RAISE_APPLICATION_ERROR: بيطلق error برقم (-20000 to -20999) ورسالة مخصصة. ودي بتوصل للـ application/user

تمرين 2: Cursor مع IF

سهل

اكتب Cursor يقرأ كل الموظفين ويصنفهم: "عالي" لو المرتب > 10000، "متوسط" لو > 5000، "منخفض" غير كده.

PL/SQL
DECLARE
    v_level VARCHAR2(10);
BEGIN
    FOR emp IN (SELECT first_name, salary FROM employees) LOOP
        IF emp.salary > 10000 THEN v_level := 'عالي';
        ELSIF emp.salary > 5000 THEN v_level := 'متوسط';
        ELSE v_level := 'منخفض';
        END IF;
        DBMS_OUTPUT.PUT_LINE(emp.first_name || ' | ' || emp.salary || ' | ' || v_level);
    END LOOP;
END;
/

تمرين 3: Parameterized Cursor

متوسط

اعمل Cursor بياخد minimum salary كـ parameter وبيطبع كل الموظفين اللي مرتبهم أكتر منه. استخدمه مرتين: مرة بـ 5000 ومرة بـ 10000.

PL/SQL
DECLARE
    CURSOR c_high_earners(p_min_sal NUMBER) IS
        SELECT first_name, salary FROM employees
        WHERE salary > p_min_sal ORDER BY salary DESC;
BEGIN
    DBMS_OUTPUT.PUT_LINE('=== مرتب > 5000 ===');
    FOR emp IN c_high_earners(5000) LOOP
        DBMS_OUTPUT.PUT_LINE(emp.first_name || ': ' || emp.salary);
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('=== مرتب > 10000 ===');
    FOR emp IN c_high_earners(10000) LOOP
        DBMS_OUTPUT.PUT_LINE(emp.first_name || ': ' || emp.salary);
    END LOOP;
END;
/

متوسط

تمرين 5: User-Defined Exception

متوسط

اكتب برنامج يفحص عمر موظف. لو العمر أقل من 18 يطلق Exception مخصص "e_too_young". لو أكتر من 65 يطلق "e_too_old".

PL/SQL
DECLARE
    e_too_young EXCEPTION;
    e_too_old   EXCEPTION;
    v_age NUMBER := 16;
BEGIN
    IF v_age < 18 THEN
        RAISE e_too_young;
    ELSIF v_age > 65 THEN
        RAISE e_too_old;
    ELSE
        DBMS_OUTPUT.PUT_LINE('العمر مقبول: ' || v_age);
    END IF;
EXCEPTION
    WHEN e_too_young THEN
        DBMS_OUTPUT.PUT_LINE('خطأ: العمر ' || v_age || ' أقل من 18!');
    WHEN e_too_old THEN
        DBMS_OUTPUT.PUT_LINE('خطأ: العمر ' || v_age || ' فوق سن التقاعد!');
END;
/

تمرين 6: Cursor + Exception معاً

صعب

اعمل Procedure اسمها show_dept_employees بتاخد department_id وبتطبع كل موظفينه. لو القسم مش موجود أو فاضي اطبع رسالة مناسبة.

PL/SQL
CREATE OR REPLACE PROCEDURE show_dept_employees(
    p_dept_id IN NUMBER
)
IS
    v_dept_name departments.department_name%TYPE;
    v_count NUMBER := 0;
BEGIN
    SELECT department_name INTO v_dept_name
    FROM departments WHERE department_id = p_dept_id;

    DBMS_OUTPUT.PUT_LINE('قسم: ' || v_dept_name);
    DBMS_OUTPUT.PUT_LINE('-------------------');

    FOR emp IN (
        SELECT first_name, salary FROM employees
        WHERE department_id = p_dept_id ORDER BY salary DESC
    ) LOOP
        DBMS_OUTPUT.PUT_LINE(emp.first_name || ': ' || emp.salary);
        v_count := v_count + 1;
    END LOOP;

    IF v_count = 0 THEN
        DBMS_OUTPUT.PUT_LINE('القسم فاضي - مفيش موظفين!');
    ELSE
        DBMS_OUTPUT.PUT_LINE('إجمالي: ' || v_count || ' موظف');
    END IF;

EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('القسم ' || p_dept_id || ' مش موجود!');
END;
/

EXEC show_dept_employees(20);
EXEC show_dept_employees(999);

تمرين 7: RAISE_APPLICATION_ERROR

صعب

اعمل Procedure اسمها transfer_employee بتنقل موظف لقسم تاني. لازم تفحص: الموظف موجود؟ القسم الجديد موجود؟ مش نفس القسم القديم؟ استخدم RAISE_APPLICATION_ERROR.

PL/SQL
CREATE OR REPLACE PROCEDURE transfer_employee(
    p_emp_id   IN NUMBER,
    p_new_dept IN NUMBER
)
IS
    v_old_dept employees.department_id%TYPE;
    v_dept_exists NUMBER;
BEGIN
    -- فحص الموظف
    BEGIN
        SELECT department_id INTO v_old_dept
        FROM employees WHERE employee_id = p_emp_id;
    EXCEPTION
        WHEN NO_DATA_FOUND THEN
            RAISE_APPLICATION_ERROR(-20001, 'الموظف ' || p_emp_id || ' مش موجود!');
    END;

    -- فحص القسم الجديد
    SELECT COUNT(*) INTO v_dept_exists
    FROM departments WHERE department_id = p_new_dept;
    IF v_dept_exists = 0 THEN
        RAISE_APPLICATION_ERROR(-20002, 'القسم ' || p_new_dept || ' مش موجود!');
    END IF;

    -- مش نفس القسم؟
    IF v_old_dept = p_new_dept THEN
        RAISE_APPLICATION_ERROR(-20003, 'الموظف أصلاً في القسم ده!');
    END IF;

    -- التنفيذ
    UPDATE employees SET department_id = p_new_dept
    WHERE employee_id = p_emp_id;
    DBMS_OUTPUT.PUT_LINE('تم النقل من قسم ' || v_old_dept || ' لقسم ' || p_new_dept);
    COMMIT;
END;
/

تمرين 8: تقرير شامل بـ Cursor

تحدي

اعمل Procedure اسمها company_report بتطبع تقرير لكل الأقسام: اسم القسم، عدد الموظفين، متوسط المرتب، والموظف صاحب أعلى مرتب.

PL/SQL
CREATE OR REPLACE PROCEDURE company_report
IS
    v_top_name employees.first_name%TYPE;
    v_top_sal  employees.salary%TYPE;
BEGIN
    DBMS_OUTPUT.PUT_LINE('╔═══════════════════════════════════════════╗');
    DBMS_OUTPUT.PUT_LINE('              تقرير الشركة الشامل           ');
    DBMS_OUTPUT.PUT_LINE('╠═══════════════════════════════════════════╣');

    FOR dept IN (
        SELECT d.department_id, d.department_name,
               COUNT(e.employee_id) AS cnt,
               ROUND(NVL(AVG(e.salary),0)) AS avg_sal
        FROM departments d
        LEFT JOIN employees e ON d.department_id = e.department_id
        GROUP BY d.department_id, d.department_name
        ORDER BY cnt DESC
    ) LOOP
        DBMS_OUTPUT.PUT_LINE('📁 ' || dept.department_name);
        DBMS_OUTPUT.PUT_LINE('   عدد الموظفين: ' || dept.cnt);
        DBMS_OUTPUT.PUT_LINE('   متوسط المرتب: ' || dept.avg_sal);

        IF dept.cnt > 0 THEN
            SELECT first_name, salary INTO v_top_name, v_top_sal
            FROM employees WHERE department_id = dept.department_id
            AND salary = (SELECT MAX(salary) FROM employees
                          WHERE department_id = dept.department_id)
            AND ROWNUM = 1;
            DBMS_OUTPUT.PUT_LINE('   أعلى مرتب: ' || v_top_name || ' (' || v_top_sal || ')');
        END IF;

        DBMS_OUTPUT.PUT_LINE('   ---');
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('╚═══════════════════════════════════════════╝');
END;

ملخص اللي اتعلمناه

  • Implicit Cursor: Oracle بيعمله تلقائي مع DML + SQL%ROWCOUNT, SQL%FOUND
  • Explicit Cursor: DECLARE → OPEN → FETCH → CLOSE (4 خطوات)
  • Cursor FOR LOOP: أسهل طريقة! مش محتاج OPEN/FETCH/CLOSE
  • Inline Cursor: FOR emp IN (SELECT ...) بدون DECLARE
  • Parameterized Cursor: بتبعت قيم مختلفة كل مرة
  • FOR UPDATE + WHERE CURRENT OF: لتحديث الصف الحالي
  • NO_DATA_FOUND: أشهر Exception - SELECT INTO مرجعش نتيجة
  • TOO_MANY_ROWS: SELECT INTO رجّع أكتر من صف
  • WHEN OTHERS: catch-all لأي خطأ مش متوقع (لازم تكون آخر WHEN)
  • User-Defined Exception: RAISE لإطلاقها
  • RAISE_APPLICATION_ERROR: رقم خطأ (-20000 to -20999) + رسالة مخصصة
  • SQLCODE و SQLERRM: لمعرفة رقم ورسالة الخطأ
