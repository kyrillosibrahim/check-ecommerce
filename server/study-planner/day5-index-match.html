تشبيه: VLOOKUP vs INDEX+MATCH

تخيل إن VLOOKUP هو GPS قديم - بيوصلك بس في اتجاه واحد بس (يمين). لكن INDEX + MATCH هو GPS حديث - بيوصلك لأي مكان في أي اتجاه! لو عايز تبقى محترف Excel، لازم تتعلم الكومبو ده.

لو اتعلمت VLOOKUP، فأنت كداخد خطوة كويسة. بس الحقيقة إن VLOOKUP عنده قيود كتيرة بتخليه مش عملي في مواقف كتيرة. هنا بييجي دور الكومبو الأقوى: INDEX + MATCH.

الدالة الأولى

دالة INDEX

دالة INDEX بسيطة جداً: بتديها نطاق (Range) ورقم صف (ورقم عمود اختيارياً)، وبترجعلك القيمة اللي في المكان ده.

الصيغة الأساسية

Excel Formula
=INDEX(array, row_num, [col_num])
  • array - النطاق أو الجدول اللي عايز تجيب منه القيمة
  • row_num - رقم الصف جوا النطاق
  • col_num - (اختياري) رقم العمود جوا النطاق

مثال 1: INDEX مع عمود واحد

عندنا قائمة بأسماء الموظفين ونعايز نجيب الاسم اللي في الصف التالت:

A
1أحمد
2محمد
3سارة
4فاطمة
5خالد
Excel Formula
=INDEX(A1:A5, 3)
// النتيجة: سارة
ببساطة: INDEX بتقولها "روحي للنطاق ده وهاتيلي القيمة اللي في الصف رقم 3" - فبترجعلك "سارة".

مثال 2: INDEX مع جدول كامل (صفوف وأعمدة)

لو عندنا جدول فيه أكتر من عمود:

A (الاسم)B (القسم)C (المرتب)
1أحمدالمبيعات5000
2محمدالبرمجة8000
3سارةالتسويق6000
Excel Formula
=INDEX(A1:C3, 2, 2)
// النتيجة: البرمجة (الصف 2، العمود 2)
ملاحظة مهمة: أرقام الصفوف والأعمدة في INDEX هي أرقام نسبية داخل النطاق - مش أرقام الصفوف في الشيت كلها. يعني الصف الأول في النطاق هو رقم 1 حتى لو كان في الصف 100 في الشيت.
الدالة الثانية

دالة MATCH

دالة MATCH بتدور على قيمة معينة جوا نطاق وبترجعلك موقعها (رقم ترتيبها). مش بترجع القيمة نفسها - بترجع رقم المكان!

الصيغة الأساسية

Excel Formula
=MATCH(lookup_value, lookup_array, [match_type])
  • lookup_value - القيمة اللي بتدور عليها
  • lookup_array - النطاق اللي هتدور فيه (صف واحد أو عمود واحد)
  • match_type - نوع المطابقة

أنواع المطابقة (match_type)

القيمةالنوعالشرحهل البيانات لازم مرتبة؟
0مطابقة تامةبيدور على القيمة بالظبط (الأكثر استخداماً)لا
1أقل من أو يساويبيرجع أكبر قيمة أقل من أو تساوي القيمة المطلوبةنعم (تصاعدي)
-1أكبر من أو يساويبيرجع أصغر قيمة أكبر من أو تساوي القيمة المطلوبةنعم (تنازلي)
مهم جداً: في 99% من الحالات هتستخدم 0 (مطابقة تامة). لو نسيت تكتب match_type، Excel هيستخدم 1 كقيمة افتراضية وده ممكن يديك نتائج غلط!

مثال: MATCH بالمطابقة التامة

A
1أحمد
2محمد
3سارة
4فاطمة
5خالد
Excel Formula
=MATCH("سارة", A1:A5, 0)
// النتيجة: 3 (سارة موجودة في المكان الثالث)
📍

تشبيه: MATCH زي Google Maps!

تخيل إنك بتسأل Google Maps "فين مطعم البيك؟" - مش هيجيبلك الأكل، هيجيبلك العنوان (الموقع). كده بالظبط MATCH بتشتغل: بتقولها "فين سارة؟" فبتقولك "في المكان رقم 3".

الكومبو السحري

كيف تعمل INDEX + MATCH معاً؟

الفكرة بسيطة: MATCH بتلاقي المكان، وINDEX بتجيب القيمة من المكان ده. لما تحطهم مع بعض، بيعملوا بحث كامل!

الصيغة المشتركة

Excel Formula
=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))

تفكيك الخطوات

خلينا نشوف إزاي الكومبو بيشتغل خطوة بخطوة. عندنا الجدول ده وعايزين نلاقي مرتب "سارة":

A (الاسم)B (المرتب)
1أحمد5000
2محمد8000
3سارة6000
4فاطمة7000
Excel Formula
=INDEX(B1:B4, MATCH("سارة", A1:A4, 0))
الخطوة 1 MATCH بتدور على "سارة" في A1:A4
→
الخطوة 2 MATCH بتلاقيها في المكان رقم 3
→
الخطوة 3 المعادلة بتصبح: =INDEX(B1:B4, 3)
→
النتيجة INDEX بترجع القيمة في الصف 3 من B = 6000
الخلاصة: MATCH بتقول "سارة في الصف 3"، و INDEX بتقول "القيمة في الصف 3 من عمود المرتبات هي 6000". النتيجة النهائية = 6000
🏢

تشبيه: الاستقبال في الشركة

تخيل إنك رحت شركة وسألت موظف الاستقبال (MATCH): "فين مكتب سارة؟" - فقالك "الدور التالت". بعدها رحت للدور التالت (INDEX) ولقيت المعلومة اللي عايزها (المرتب). MATCH بتلاقي المكان، INDEX بتجيب المعلومة!

تطبيق عملي

أمثلة عملية

مثال 1: البحث عن مرتب موظف

عندنا جدول بيانات الموظفين وعايزين نلاقي مرتب "خالد":

A (الرقم)B (الاسم)C (القسم)D (المرتب)
1101أحمدالمبيعات5000
2102محمدالبرمجة8000
3103سارةالتسويق6000
4104خالدالمحاسبة7500
5105فاطمةالبرمجة9000
Excel Formula
=INDEX(D1:D5, MATCH("خالد", B1:B5, 0))
// النتيجة: 7500

مثال 2: البحث عن قسم الموظف بالرقم الوظيفي

Excel Formula
=INDEX(C1:C5, MATCH(103, A1:A5, 0))
// النتيجة: التسويق (الرقم 103 = سارة = قسم التسويق)

مثال 3: البحث عن سعر منتج

A (المنتج)B (الفئة)C (السعر)D (المخزون)
1لابتوبإلكترونيات1500025
2موبايلإلكترونيات800050
3كرسيأثاث2000100
4مكتبأثاث500030
Excel Formula
// البحث عن سعر الموبايل
=INDEX(C1:C4, MATCH("موبايل", A1:A4, 0))
// النتيجة: 8000

// البحث عن مخزون المكتب
=INDEX(D1:D4, MATCH("مكتب", A1:A4, 0))
// النتيجة: 30
لاحظ: في كل الأمثلة دي، MATCH بتدور في عمود والنتيجة بتتجاب من عمود تاني. العمودين لازم يكونوا بنفس عدد الصفوف عشان المعادلة تشتغل صح.
الميزة الخارقة

البحث لليسار (Left Lookup)

دي واحدة من أهم المميزات اللي بتخلي INDEX + MATCH أقوى من VLOOKUP. في VLOOKUP، لازم عمود البحث يكون أول عمود على الشمال. لكن INDEX + MATCH مش عنده المشكلة دي!

المشكلة: لو عمود البحث على اليمين

A (الاسم)B (القسم)C (الرقم الوظيفي)
1أحمدالمبيعات101
2محمدالبرمجة102
3سارةالتسويق103

عايزين نلاقي اسم الموظف اللي رقمه 101. الرقم في العمود C والاسم في العمود A (يعني البحث لازم يكون لليسار).

VLOOKUP (مش هيعرف!)

Excel Formula
=VLOOKUP(101, C1:A3, ???)
// ❌ مش هيشتغل!
// VLOOKUP بيبحث فقط من
// الشمال لليمين
VLOOKUP عاجز هنا! لأن عمود البحث (C) لازم يكون أول عمود في النطاق، لكنه مش أول عمود.
VS

INDEX + MATCH (سهل!)

Excel Formula
=INDEX(A1:A3, MATCH(101, C1:C3, 0))
// ✅ النتيجة: أحمد
// INDEX + MATCH مش مهم
// ترتيب الأعمدة!
INDEX + MATCH بيقدر! لأن MATCH بتدور في أي مكان و INDEX بتجيب من أي مكان - مفيش قيود على الاتجاه.
"البحث لليسار هو السبب الأول اللي بيخلي الناس تتحول من VLOOKUP لـ INDEX + MATCH. لو واجهتك المشكلة دي مرة واحدة، هتفهم ليه INDEX + MATCH أفضل."
مستوى متقدم

INDEX + MATCH ثنائي الأبعاد

واحدة من أقوى حاجات INDEX + MATCH إنك تقدر تعمل بحث في اتجاهين: تحدد الصف والعمود في نفس الوقت باستخدام MATCH مرتين!

الصيغة

Excel Formula
=INDEX(data_range, MATCH(row_value, row_headers, 0), MATCH(col_value, col_headers, 0))

مثال: جدول المبيعات الربع سنوية

عندنا جدول فيه مبيعات كل موظف في كل ربع سنة. عايزين نعرف مبيعات "محمد" في "Q3":

Q1Q2Q3Q4
أحمد12000150001300018000
محمد20000220002500028000
سارة18000190002100024000
خالد10000110001400016000
Excel Formula
// البيانات في B2:E5
// أسماء الموظفين في A2:A5
// رؤوس الأعمدة في B1:E1

=INDEX(B2:E5, MATCH("محمد", A2:A5, 0), MATCH("Q3", B1:E1, 0))
// النتيجة: 25000
الخطوة 1 MATCH الأولى: "محمد" في A2:A5 = الصف 2
→
الخطوة 2 MATCH الثانية: "Q3" في B1:E1 = العمود 3
→
الخطوة 3 INDEX(B2:E5, 2, 3) = 25000
ملحوظة: الميزة دي مفيش مثيل ليها في VLOOKUP! مش محتاج تعرف رقم العمود مسبقاً - MATCH بتلاقيه لك تلقائياً. ده معناه لو حد أضاف عمود جديد في النص، المعادلة بتاعتك هتفضل شغالة صح.
المقارنة الكاملة

INDEX + MATCH vs VLOOKUP

خلينا نعمل مقارنة شاملة بين الاتنين عشان تعرف امتى تستخدم أنهي واحد:

VLOOKUP

  • ✅ أسهل في الكتابة والفهم
  • ✅ كافي للمهام البسيطة
  • ❌ بيبحث يمين بس
  • ❌ بيحتاج رقم عمود ثابت
  • ❌ لو أضفت عمود - المعادلة تبوظ
  • ❌ أبطأ مع البيانات الكبيرة
  • ❌ مفيش بحث ثنائي الأبعاد
VS

INDEX + MATCH

  • ✅ بيبحث في أي اتجاه
  • ✅ آمن لما تضيف أو تحذف أعمدة
  • ✅ أسرع بكتير مع الداتا الكبيرة
  • ✅ بحث ثنائي الأبعاد
  • ✅ بيدعم شروط متعددة
  • ✅ أكثر مرونة وقوة
  • ❌ المعادلة أطول شوية
الميزةVLOOKUPINDEX + MATCHالفائز
سهولة الكتابةسهلمحتاج تمرينVLOOKUP
اتجاه البحثيمين فقطأي اتجاهINDEX+MATCH
السرعةعاديأسرعINDEX+MATCH
أمان الأعمدةغير آمنآمنINDEX+MATCH
بحث ثنائي الأبعادلانعمINDEX+MATCH
شروط متعددةصعبسهلINDEX+MATCH
نصيحة: لو أنت لسه مبتدئ وعندك مهام بسيطة، VLOOKUP كويس. بس لو عايز تحترف Excel وتشتغل مع بيانات كبيرة أو معقدة، لازم تتعلم INDEX + MATCH.

ليه INDEX + MATCH أسرع؟

VLOOKUP بيحتاج يقرأ كل الأعمدة من عمود البحث لحد عمود النتيجة. لكن INDEX + MATCH بيحتاج يقرأ عمودين بس: عمود البحث وعمود النتيجة. يعني لو عندك جدول فيه 50 عمود وعايز تجيب بيانات من العمود الأخير:

  • VLOOKUP - هيقرأ الـ 50 عمود كلهم
  • INDEX + MATCH - هيقرأ عمودين بس
مستوى احترافي

INDEX + MATCH مع شروط متعددة

أحياناً بتحتاج تدور على قيمة بناءً على أكتر من شرط. مثلاً: عايز مرتب "أحمد" اللي في قسم "المبيعات" (لو فيه أكتر من أحمد في الشركة).

الصيغة (Array Formula)

Excel Formula - Array
// لازم تضغط Ctrl + Shift + Enter بدل Enter عادي!
{=INDEX(return_range, MATCH(1, (crit1=range1)*(crit2=range2), 0))}

مثال: البحث بالاسم والقسم

A (الاسم)B (القسم)C (المرتب)
1أحمدالمبيعات5000
2محمدالبرمجة8000
3أحمدالبرمجة9000
4سارةالتسويق6000
5أحمدالمحاسبة7000

فيه 3 موظفين اسمهم "أحمد"! لو استخدمت INDEX + MATCH عادي، هيجيب أول "أحمد" بس. لكن عايزين "أحمد" اللي في قسم "المبيعات":

Excel Formula - Array (Ctrl+Shift+Enter)
{=INDEX(C1:C5, MATCH(1, ("أحمد"=A1:A5)*("المبيعات"=B1:B5), 0))}
// النتيجة: 5000

إزاي بتشتغل؟

تفكيك المعادلة خطوة بخطوة

الخطوة 1 "أحمد"=A1:A5 بيعمل مصفوفة: {TRUE,FALSE,TRUE,FALSE,TRUE}
→
الخطوة 2 "المبيعات"=B1:B5 بيعمل مصفوفة: {TRUE,FALSE,FALSE,FALSE,FALSE}
الخطوة 3 ضرب المصفوفتين: {1*1, 0*0, 1*0, 0*0, 1*0} = {1,0,0,0,0}
→
الخطوة 4 MATCH بتدور على 1 = المكان رقم 1
→
النتيجة INDEX(C1:C5, 1) = 5000
مهم جداً: لازم تضغط Ctrl + Shift + Enter بدل Enter عادي عشان دي Array Formula. لو ضغطت Enter بس، المعادلة مش هتشتغل صح. هتلاحظ إن Excel بيحط أقواس {} حوالين المعادلة تلقائياً.
ملحوظة لمستخدمي Excel 365 / 2021: في الإصدارات الحديثة، مش محتاج تضغط Ctrl+Shift+Enter - Excel بيتعامل مع Array Formulas تلقائياً. بس اكتب المعادلة عادي واضغط Enter.

نصائح وحيل

📌

استخدم $ (مراجع مطلقة)

لما تنسخ المعادلة لخلايا تانية، استخدم $A$1:$A$10 عشان النطاق ما يتغيرش

🔤

MATCH مش حساسة للحالة

MATCH مش بتفرق بين حروف كبيرة وصغيرة في الإنجليزي. "Ahmed" = "ahmed"

📊

استخدم أسماء النطاقات

سمي النطاقات (Name Manager) عشان المعادلة تبقى أسهل في القراءة

⚠️

دايماً اكتب 0

دايماً اكتب 0 كآخر parameter في MATCH عشان تضمن مطابقة تامة

نصيحة 1: استخدام Named Ranges

قبل (صعبة القراءة)

Excel Formula
=INDEX($D$2:$D$100, MATCH(G2, $B$2:$B$100, 0))

بعد (سهلة القراءة)

Excel Formula
=INDEX(Salaries, MATCH(G2, EmployeeNames, 0))

نصيحة 2: التعامل مع الأخطاء بـ IFERROR

Excel Formula
// لو القيمة مش موجودة، بدل ما يظهر خطأ #N/A، هيظهر "غير موجود"
=IFERROR(INDEX(B1:B10, MATCH("القيمة", A1:A10, 0)), "غير موجود")

نصيحة 3: استخدام MATCH مع Wildcards

Excel Formula
// البحث عن أي اسم بيبدأ بـ "أح" (مثل أحمد، أحلام، إلخ)
=INDEX(B1:B10, MATCH("أح*", A1:A10, 0))

// البحث عن كود منتج بيبدأ بـ "PRD" وبينتهي بأي حاجة
=INDEX(B1:B10, MATCH("PRD-???", A1:A10, 0))
// ? = حرف واحد، * = أي عدد من الحروف
Wildcards: النجمة * بتمثل أي عدد من الحروف، وعلامة الاستفهام ? بتمثل حرف واحد. دول بيشتغلوا بس مع match_type = 0 (مطابقة تامة).
تجنب الأخطاء

أخطاء شائعة

❌ خطأ 1: نسيان كتابة 0 في MATCH

الخطأ
// ❌ غلط - مفيش match_type
=INDEX(B1:B10, MATCH("أحمد", A1:A10))

// ✅ صح - match_type = 0
=INDEX(B1:B10, MATCH("أحمد", A1:A10, 0))
السبب: القيمة الافتراضية لـ match_type هي 1 (أقل من أو يساوي)، مش 0 (مطابقة تامة). لو نسيت تكتب 0، ممكن تاخد نتيجة غلط بدون ما Excel يديك خطأ!

❌ خطأ 2: أحجام النطاقات مختلفة

الخطأ
// ❌ غلط - نطاق INDEX فيه 10 صفوف ونطاق MATCH فيه 5
=INDEX(B1:B10, MATCH("أحمد", A1:A5, 0))

// ✅ صح - النطاقين بنفس الحجم
=INDEX(B1:B10, MATCH("أحمد", A1:A10, 0))
السبب: لو MATCH لقت القيمة في الصف 8 بس نطاق MATCH فيه 5 صفوف بس، مش هتلاقيها وهتطلع خطأ #N/A. لازم النطاقين يبدأوا من نفس الصف وينتهوا عند نفس الصف.

❌ خطأ 3: استخدام نطاق ثنائي الأبعاد في MATCH

الخطأ
// ❌ غلط - MATCH بتاخد صف واحد أو عمود واحد بس
=MATCH("أحمد", A1:C10, 0)

// ✅ صح - عمود واحد
=MATCH("أحمد", A1:A10, 0)
السبب: MATCH بتدور في بُعد واحد بس (صف واحد أو عمود واحد). لو أديتها نطاق ثنائي الأبعاد، هتطلع خطأ #N/A.

❌ خطأ 4: مسافات زيادة أو اختلاف في البيانات

الخطأ
// لو الخلية فيها "أحمد " (بمسافة في الآخر)
// والمعادلة بتدور على "أحمد" (بدون مسافة)
// المعادلة مش هتلاقيه!

// الحل: استخدم TRIM لإزالة المسافات
=INDEX(B1:B10, MATCH("أحمد", TRIM(A1:A10), 0))

❌ خطأ 5: الخلط بين أرقام وتكست

الخطأ
// لو الأرقام في الشيت متخزنة كتكست
// وأنت بتدور عليها كأرقام - مش هيلاقيها!

// ❌ لو العمود فيه "101" كتكست
=MATCH(101, A1:A10, 0) // #N/A!

// ✅ الحل: دور عليها كتكست
=MATCH("101", A1:A10, 0) // هيلاقيها

تمارين

بيانات التمارين: كل التمارين بتستخدم الجدول ده. الأسماء في A2:A8، الأقسام في B2:B8، المرتبات في C2:C8، والتقييم في D2:D8.

تمرين 1: البحث عن مرتب موظف

سهل

اكتب معادلة تجيب مرتب الموظف "خالد" باستخدام INDEX + MATCH.

تلميح: ابحث عن "خالد" في عمود الأسماء (A2:A8) واستخدم INDEX لاسترجاع القيمة من عمود المرتبات (C2:C8).
الحل
=INDEX(C2:C8, MATCH("خالد", A2:A8, 0))
// النتيجة: 7500

تمرين 2: البحث عن تقييم موظف

سهل

اكتب معادلة تجيب تقييم الموظفة "فاطمة" باستخدام INDEX + MATCH.

تلميح: ابحث عن "فاطمة" في A2:A8 واسترجع القيمة من D2:D8 (عمود التقييم).
الحل
=INDEX(D2:D8, MATCH("فاطمة", A2:A8, 0))
// النتيجة: ممتاز

تمرين 3: البحث العكسي (لليسار)

متوسط

اكتب معادلة تجيب اسم الموظف اللي مرتبه 9000. لاحظ إن عمود المرتبات (C) على يمين عمود الأسماء (A) - يعني لازم بحث لليسار!

تلميح: ابحث عن 9000 في عمود المرتبات (C2:C8) واسترجع الاسم من عمود الأسماء (A2:A8). VLOOKUP مش هيعرف يعمل كده!
الحل
=INDEX(A2:A8, MATCH(9000, C2:C8, 0))
// النتيجة: فاطمة

تمرين 4: البحث عن القسم بالمرتب

متوسط

اكتب معادلة تجيب اسم القسم اللي فيه الموظف اللي مرتبه 6000.

تلميح: ابحث عن 6000 في C2:C8 واسترجع القيمة من B2:B8.
الحل
=INDEX(B2:B8, MATCH(6000, C2:C8, 0))
// النتيجة: التسويق

تمرين 5: استخدام IFERROR

متوسط

اكتب معادلة تدور على مرتب موظف اسمه "يوسف". لو مش موجود، المعادلة تظهر "الموظف غير موجود" بدل خطأ #N/A.

تلميح: غلف معادلة INDEX + MATCH كلها جوا IFERROR. الشكل العام: =IFERROR(INDEX+MATCH, "رسالة الخطأ")
الحل
=IFERROR(INDEX(C2:C8, MATCH("يوسف", A2:A8, 0)), "الموظف غير موجود")
// النتيجة: الموظف غير موجود (لأن يوسف مش في الجدول)

تمرين 6: البحث بشرطين (Array Formula)

صعب

في الجدول فيه موظفين في قسم "المبيعات": أحمد (5000) وعمر (5500). اكتب معادلة تجيب مرتب الموظف "عمر" اللي في قسم "المبيعات" باستخدام شرطين.

تلميح: استخدم Array Formula مع MATCH(1, (الشرط1)*(الشرط2), 0). الشرط الأول: الاسم = "عمر"، الشرط الثاني: القسم = "المبيعات". لا تنسى Ctrl+Shift+Enter!
الحل (Ctrl+Shift+Enter)
{=INDEX(C2:C8, MATCH(1, ("عمر"=A2:A8)*("المبيعات"=B2:B8), 0))}
// النتيجة: 5500

تمرين 7: بحث ثنائي الأبعاد

صعب

عندك جدول مبيعات ربع سنوية (الأسماء في العمود A، والأرباع Q1-Q4 في الصف الأول، والبيانات في B2:E5). اكتب معادلة تجيب مبيعات "سارة" في "Q2".

Q1Q2Q3Q4
أحمد12000150001300018000
محمد20000220002500028000
سارة18000190002100024000
خالد10000110001400016000
تلميح: استخدم INDEX مع MATCH مرتين - مرة للصف ومرة للعمود. =INDEX(data, MATCH(row_val, row_range, 0), MATCH(col_val, col_range, 0))
الحل
=INDEX(B2:E5, MATCH("سارة", A2:A5, 0), MATCH("Q2", B1:E1, 0))
// النتيجة: 19000

تمرين 8: تحدي شامل - أعلى مرتب في قسم معين

صعب

اكتب معادلة تجيب اسم الموظف صاحب أعلى مرتب في قسم "البرمجة". (في الجدول الأساسي: محمد=8000، فاطمة=9000 - المفروض النتيجة فاطمة).

تلميح: هتحتاج تجمع بين INDEX + MATCH و MAX و IF. المعادلة هتكون Array Formula. الخطوات: 1) فلتر المرتبات حسب القسم باستخدام IF 2) لاقي أعلى مرتب بـ MAX 3) استخدم النتيجة مع MATCH و INDEX لإيجاد الاسم.
الحل (Ctrl+Shift+Enter)
// الطريقة 1: على خطوتين
// أولاً: لاقي أعلى مرتب في البرمجة
{=MAX(IF(B2:B8="البرمجة", C2:C8))}
// النتيجة: 9000

// ثانياً: لاقي اسم صاحب المرتب 9000 في البرمجة
{=INDEX(A2:A8, MATCH(1, (B2:B8="البرمجة")*(C2:C8=MAX(IF(B2:B8="البرمجة", C2:C8))), 0))}
// النتيجة: فاطمة

// الطريقة 2: معادلة واحدة مدمجة
{=INDEX(A2:A8, MATCH(MAX((B2:B8="البرمجة")*C2:C8), (B2:B8="البرمجة")*C2:C8, 0))}
// النتيجة: فاطمة
الملخص

ملخص اليوم الخامس

اللي اتعلمناه النهاردة

  • دالة INDEX بترجع قيمة من نطاق بناءً على رقم الصف (والعمود اختيارياً)
  • دالة MATCH بتدور على قيمة وبترجع موقعها (رقم ترتيبها) في النطاق
  • لما نجمعهم مع بعض: MATCH بتلاقي المكان، INDEX بتجيب القيمة
  • INDEX + MATCH بيقدر يعمل بحث لليسار (اللي VLOOKUP مش بيقدر يعمله)
  • INDEX + MATCH ثنائي الأبعاد بيدور في الصفوف والأعمدة في نفس الوقت
  • INDEX + MATCH أسرع وأكثر مرونة من VLOOKUP مع البيانات الكبيرة
  • Array Formula بتسمحلك تستخدم شروط متعددة في البحث
  • دايماً استخدم 0 كـ match_type في MATCH عشان مطابقة تامة
  • استخدم IFERROR عشان تتعامل مع حالة عدم وجود القيمة المطلوبة
  • Named Ranges بتخلي المعادلة أسهل في القراءة والصيانة
"INDEX + MATCH هو أقوى كومبو في Excel للبحث عن البيانات. لما تتمرن عليه كويس، مش هتحتاج ترجع لـ VLOOKUP تاني! ابدأ استخدمه في شغلك اليومي وهتلاحظ الفرق."
