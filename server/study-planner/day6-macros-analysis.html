الأتمتة

إيه هي Macros؟

الـ Macro هو مجموعة من الأوامر والإجراءات اللي بتتسجل عشان Excel ينفذها تلقائياً. بدل ما تعمل نفس الخطوات كل يوم يدوياً، بتسجلها مرة واحدة وبعدها بتشغلها بضغطة زر!

🍳

تشبيه: الـ Macro زي الوصفة!

تخيل إنك بتعمل كيكة كل أسبوع. بدل ما تفتكر الخطوات كل مرة، بتكتب الوصفة مرة واحدة وبتتبعها. الـ Macro هو نفس الفكرة - بتسجل الخطوات مرة واحدة و Excel بيتبعها بالظبط كل مرة تشغلها!

إيه اللي بيحصل ورا الكواليس؟

لما بتسجل Macro، Excel بيحول كل حركة بتعملها لكود بلغة اسمها VBA (Visual Basic for Applications). مش لازم تعرف تكتب VBA عشان تستخدم Macros - بس لو فهمت الأساسيات هتقدر تعدل وتحسن الـ Macros بتاعتك.

  • تسجيل تلقائي: Excel بيراقب كل حاجة بتعملها وبيحولها لكود VBA
  • تنفيذ سريع: الـ Macro بينفذ الخطوات في ثواني حتى لو كانت بتاخد منك ساعة
  • بدون أخطاء: الكمبيوتر مش بينسى خطوة ومش بيغلط في التنسيق
  • قابل للتعديل: تقدر تفتح الكود وتعدله يدوياً لو محتاج

خطوة بخطوة

تسجيل أول Macro

خلينا نسجل أول Macro مع بعض! هنعمل Macro بسيط بيقوم بتنسيق خلية (Bold + لون خلفية + توسيط).

الطريقة الأولى: من تاب View

  1. افتح ملف Excel جديد واكتب أي بيانات في الخلايا
  2. روح لتاب View في الشريط العلوي
  3. دوس على Macros واختار Record Macro
  4. هتظهر نافذة - اكتب اسم الـ Macro (مثلاً FormatHeader) بدون مسافات
  5. اختار Shortcut Key (اختياري) - مثلاً Ctrl+Shift+H
  6. في Store macro in اختار This Workbook
  7. دوس OK - التسجيل بدأ دلوقتي!
  8. نفذ الخطوات اللي عايز تسجلها: اعمل Bold، غير لون الخلفية، وسط النص
  9. لما تخلص، روح View → Macros → Stop Recording

الطريقة الثانية: من تاب Developer

  1. لو تاب Developer مش ظاهر: File → Options → Customize Ribbon → فعّل Developer
  2. روح لتاب Developer
  3. دوس على Record Macro
  4. نفس الخطوات السابقة: اسم، اختصار، مكان الحفظ
  5. نفذ الخطوات اللي عايز تسجلها
  6. دوس Stop Recording من تاب Developer
نصيحة مهمة: قبل ما تبدأ التسجيل، خطط الخطوات اللي هتعملها. لأن الـ Macro بيسجل كل حاجة بتعملها - حتى الأخطاء! لو غلطت وعملت Undo أثناء التسجيل، الـ Undo نفسه هيتسجل.
قواعد تسمية الـ Macro: الاسم لازم يبدأ بحرف (مش رقم)، مفيهوش مسافات (استخدم _ بدل المسافة)، ومش بيقبل رموز خاصة. أمثلة صحيحة: Format_Report، CleanData، MonthlyReport1.
التشغيل

تشغيل Macro

بعد ما سجلت الـ Macro، عندك أكتر من طريقة تشغله:

الطريقة 1: من قائمة Macros

  1. روح View → Macros → View Macros (أو اضغط Alt+F8)
  2. اختار الـ Macro اللي عايز تشغله من القائمة
  3. دوس Run

الطريقة 2: اختصار الكيبورد

لو حددت Shortcut Key وقت التسجيل (مثلاً Ctrl+Shift+H)، بتضغط الاختصار وبيشتغل فوراً. دي أسرع طريقة!

الطريقة 3: ربط الـ Macro بزرار (Button)

  1. روح تاب Developer → Insert → اختار Button (Form Control)
  2. ارسم الزرار على الشيت بالماوس
  3. هتظهر نافذة - اختار الـ Macro اللي عايز تربطه بالزرار
  4. دوس OK
  5. كلك يمين على الزرار → Edit Text عشان تغير النص اللي عليه
الأفضل للمستخدمين: لو هتشارك الملف مع ناس تانية، الزرار هو أسهل طريقة عشان أي حد يقدر يشغل الـ Macro بدون ما يعرف اختصارات أو يفتح قوائم.

الطريقة 4: من تاب Developer

روح تاب Developer → Macros → اختار الـ Macro → Run. نفس الطريقة الأولى بس من مكان مختلف.

ورا الكواليس

نظرة على VBA

مش لازم تبقى خبير VBA عشان تستخدم Macros. بس فهم الأساسيات هيساعدك تعدل الـ Macros المسجلة وتحسنها.

فتح محرر VBA

اضغط Alt+F11 عشان تفتح محرر VBA. هتلاقي الكود بتاع الـ Macros في Modules على الشمال.

هيكل كود الـ Macro

كل Macro بيبدأ بـ Sub وبينتهي بـ End Sub:

VBA Code
Sub FormatHeader()
'
' FormatHeader Macro
' تنسيق العناوين
'
    Selection.Font.Bold = True
    Selection.Font.Size = 14
    Selection.Font.Color = RGB(255, 255, 255)
    Selection.Interior.Color = RGB(0, 0, 128)
    Selection.HorizontalAlignment = xlCenter
End Sub

تعديلات بسيطة تقدر تعملها

تغيير نطاق الخلايا

VBA Code
' بدل ما يشتغل على الخلية المحددة بس
Selection.Font.Bold = True

' خليه يشتغل على نطاق محدد
Range("A1:D1").Font.Bold = True

تغيير القيم والألوان

VBA Code
' تغيير حجم الخط
Range("A1").Font.Size = 16

' تغيير لون الخلفية (أحمر)
Range("A1").Interior.Color = RGB(255, 0, 0)

' كتابة قيمة في خلية
Range("A1").Value = "التقرير الشهري"
مش لازم تحفظ كل ده: الهدف إنك تفهم الهيكل العام. لما تسجل Macro وتفتح الكود، هتقدر تتعرف على الأجزاء وتعدلها. مع الوقت هتتعلم أكتر وأكتر.
تطبيقات عملية

أمثلة عملية على Macros

مثال 1: تنسيق تقرير كامل

Macro بيعمل تنسيق احترافي لأول صف (العناوين) مع حدود لكل الجدول:

VBA Code
Sub FormatReport()
    ' تنسيق صف العناوين
    Rows(1).Font.Bold = True
    Rows(1).Font.Size = 12
    Rows(1).Interior.Color = RGB(0, 51, 102)
    Rows(1).Font.Color = RGB(255, 255, 255)
    Rows(1).HorizontalAlignment = xlCenter

    ' إضافة حدود للجدول
    ActiveSheet.UsedRange.Borders.LineStyle = xlContinuous
    ActiveSheet.UsedRange.Borders.Weight = xlThin

    ' ضبط عرض الأعمدة تلقائياً
    Cells.EntireColumn.AutoFit
End Sub

مثال 2: مسح وإعادة تعيين فورم

Macro بيمسح بيانات معينة ويرجع الخلايا لحالتها الأصلية:

VBA Code
Sub ClearForm()
    ' مسح خلايا الإدخال بس (مش العناوين)
    Range("B2:B10").ClearContents
    Range("D2:D10").ClearContents

    ' إرجاع المؤشر لأول خلية إدخال
    Range("B2").Select

    ' رسالة تأكيد
    MsgBox "تم مسح البيانات بنجاح!"
End Sub

مثال 3: حفظ تلقائي بالتاريخ والوقت

Macro بيحفظ نسخة من الملف باسم فيه التاريخ والوقت:

VBA Code
Sub SaveWithTimestamp()
    Dim fileName As String
    Dim savePath As String

    ' إنشاء اسم الملف بالتاريخ
    fileName = "Report_" & Format(Now, "yyyy-mm-dd_hh-mm")
    savePath = ThisWorkbook.Path & "\" & fileName & ".xlsm"

    ' حفظ نسخة
    ThisWorkbook.SaveCopyAs savePath

    MsgBox "تم الحفظ: " & fileName
End Sub
ملاحظة: الأمثلة دي تقدر تسجلها بالـ Macro Recorder (ماعدا مثال 3 اللي محتاج كتابة يدوية). جرب تسجل الخطوات وبعدين قارن الكود الناتج بالأمثلة فوق!
حفظ الملف

حفظ ملف يحتوي Macros

لو ملفك فيه Macros، مش هينفع تحفظه كملف .xlsx عادي. لازم تحفظه بصيغة خاصة!

صيغة الحفظ الصحيحة

  1. اضغط File → Save As
  2. في Save as type، اختار Excel Macro-Enabled Workbook (*.xlsm)
  3. اختار مكان الحفظ واضغط Save

.xlsx (عادي)

  • ❌ مش بيحفظ Macros
  • ❌ لو حفظت بيها، الـ Macros هتتمسح
  • ✅ آمن - مفيهوش كود ممكن يكون ضار
VS

.xlsm (Macro-Enabled)

  • ✅ بيحفظ الـ Macros كاملة
  • ✅ بيشتغل عادي زي .xlsx
  • ⚠️ محتاج تفعيل Macros عند الفتح

التحليل الإحصائي

إيه هو Data Analysis؟

الـ Data Analysis ToolPak هو إضافة (Add-in) في Excel بتوفر أدوات إحصائية متقدمة. بدل ما تكتب معادلات معقدة بنفسك، الأدوات دي بتعمل التحليل كامل بخطوات بسيطة.

تفعيل Analysis ToolPak

الأداة مش مفعلة افتراضياً. لازم تفعلها الأول:

  1. روح File → Options
  2. اختار Add-ins من القائمة على الشمال
  3. في الأسفل عند Manage، اختار Excel Add-ins واضغط Go
  4. ضع علامة صح على Analysis ToolPak
  5. اضغط OK
بعد التفعيل: هتلاقي زر Data Analysis ظاهر في تاب Data في مجموعة Analysis.

إحصائيات وصفية

Descriptive Statistics

الإحصائيات الوصفية بتديك ملخص شامل لبياناتك في ثواني. بدل ما تكتب كل معادلة لوحدها (AVERAGE, MEDIAN, STDEV, إلخ)، الأداة دي بتحسبهم كلهم مرة واحدة!

خطوات الاستخدام

  1. جهّز بياناتك في عمود (أو أكتر) مع عناوين في الصف الأول
  2. روح Data → Data Analysis
  3. اختار Descriptive Statistics واضغط OK
  4. في Input Range: حدد نطاق البيانات (مثلاً A1:A50)
  5. فعّل Labels in first row لو الصف الأول فيه عنوان
  6. اختار Output Range وحدد خلية لوضع النتائج فيها
  7. فعّل Summary statistics
  8. اضغط OK

التوزيع التكراري

Histogram

الـ Histogram (التوزيع التكراري) بيقسم بياناتك لفئات وبيحسب كم قيمة في كل فئة. ده بيساعدك تفهم شكل توزيع البيانات: هل أغلبها في النص؟ على الأطراف؟ متوزعة بالتساوي؟

خطوات إنشاء Histogram

  1. جهّز البيانات في عمود (مثلاً درجات الطلاب في A1:A100)
  2. اكتب حدود الفئات (Bin Range) في عمود تاني (مثلاً: 50, 60, 70, 80, 90, 100 في C1:C6)
  3. روح Data → Data Analysis → Histogram
  4. حدد Input Range (بيانات الدرجات)
  5. حدد Bin Range (حدود الفئات)
  6. اختار Output Range
  7. فعّل Chart Output عشان يرسم الشارت تلقائياً
  8. اضغط OK

تشبيه: الصناديق!

تخيل إن عندك 100 كرة (القيم) و 6 صناديق (الفئات). الـ Histogram بيقولك كل صندوق فيه كام كرة. لو صندوق فيه كرات كتيرة، ده معناه إن معظم القيم بتقع في الفئة دي.

قراءة النتائج: لو أكتر الطلاب في فئة 70-80، ده معناه إن أغلب الطلاب مستواهم متوسط-جيد. لو فيه طلاب كتير في فئة أقل من 50، ده مؤشر إن فيه مشكلة في الفهم.

البحث عن الهدف

Goal Seek

Goal Seek بيشتغل بالعكس: بدل ما تدخل المدخلات وتشوف النتيجة، أنت بتحدد النتيجة اللي عايزها وهو بيحسبلك المدخل المطلوب!

خطوات الاستخدام

  1. تأكد إن عندك معادلة في خلية النتيجة (مثلاً: =B1*B2-B3 لحساب الربح)
  2. روح Data → What-If Analysis → Goal Seek
  3. Set cell: حدد خلية النتيجة (اللي فيها المعادلة)
  4. To value: اكتب القيمة اللي عايز توصلها
  5. By changing cell: حدد الخلية اللي Goal Seek هيغير قيمتها
  6. اضغط OK وشوف النتيجة

مثال 1: إيه المرتب المطلوب عشان الميزانية تتوازن؟

AB
1الإيرادات50,000
2المرتبات???
3الإيجار10,000
4المصاريف الأخرى5,000
5الربح =B1-B2-B3-B40 (نقطة التعادل)

عايز الربح (B5) يبقى 0 (نقطة التعادل). Goal Seek هيحسب إن المرتبات (B2) لازم تبقى 35,000.

3التكلفة الإجمالية150,000
4الربح =B1*B2-B3100,000

Goal Seek هيحسب إن سعر الوحدة لازم يبقى 500 عشان الربح يبقى 100,000. (500 × 500 - 150,000 = 100,000)

ملاحظة: Goal Seek بيغير خلية واحدة بس. لو عايز تغير أكتر من خلية، استخدم Solver (أداة أكثر تقدماً) أو Scenario Manager.
جداول البيانات

Data Tables

Data Tables بتسمحلك تشوف نتائج المعادلة لمدخلات مختلفة كلها مرة واحدة في جدول منظم. عندك نوعين: جدول بمتغير واحد وجدول بمتغيرين.

One-Variable Data Table (متغير واحد)

عايز تعرف قسط القرض الشهري لو الفائدة اتغيرت من 3% لـ 8%؟

إعداد الجدول

المعادلة الأساسية:

Excel Formula
B1: مبلغ القرض = 500,000
B2: نسبة الفائدة السنوية = 5%
B3: عدد السنوات = 20
B4: القسط الشهري
=PMT(B2/12, B3*12, -B1)

خطوات إنشاء One-Variable Data Table

  1. اكتب القيم المختلفة للمتغير في عمود (مثلاً: 3%, 4%, 5%, 6%, 7%, 8% في D2:D7)
  2. في الخلية فوق العمود وعلى يمين القيم (يعني E1)، اكتب مرجع لمعادلة النتيجة: =B4
  3. حدد الجدول كامل (القيم + خلية المعادلة): D1:E7
  4. روح Data → What-If Analysis → Data Table
  5. في Column input cell: حدد خلية الفائدة B2 (لأن القيم في عمود)
  6. اضغط OK - هيحسب القسط لكل نسبة فائدة!

Two-Variable Data Table (متغيرين)

عايز تشوف تأثير تغيير السعر و الكمية على الربح في نفس الوقت؟

خطوات إنشاء Two-Variable Data Table

  1. اكتب قيم المتغير الأول في عمود (الأسعار: 50, 60, 70, 80 في D3:D6)
  2. اكتب قيم المتغير الثاني في صف (الكميات: 100, 200, 300 في E2:G2)
  3. في الزاوية (تقاطع الصف والعمود D2)، اكتب مرجع لمعادلة الربح: =B5
  4. حدد الجدول كامل: D2:G6
  5. Data → What-If Analysis → Data Table
  6. Row input cell: خلية الكمية B2
  7. Column input cell: خلية السعر B1
  8. اضغط OK

مدير السيناريوهات

Scenario Manager

Scenario Manager بيسمحلك تحفظ مجموعات مختلفة من المدخلات (سيناريوهات) وتقارن بينها. مثلاً: سيناريو متفائل، متشائم، وواقعي.

خطوات إنشاء السيناريوهات

  1. جهز النموذج المالي بتاعك مع المعادلات (مثلاً: إيرادات، تكاليف، ربح)
  2. روح Data → What-If Analysis → Scenario Manager
  3. اضغط Add لإضافة سيناريو جديد
  4. اكتب اسم السيناريو (مثلاً: Best Case)
  5. في Changing cells: حدد الخلايا اللي هتتغير (مثلاً: B1:B3)
  6. اضغط OK واكتب القيم للسيناريو ده
  7. كرر الخطوات لكل سيناريو (Worst Case, Most Likely)

مثال: تحليل مشروع جديد

المتغيرBest CaseMost LikelyWorst Case
عدد الوحدات المباعة1,000700400
سعر الوحدة150120100
التكلفة لكل وحدة607590
الربح المتوقع90,00031,5004,000

إنشاء تقرير المقارنة (Summary)

  1. في نافذة Scenario Manager، اضغط Summary
  2. اختار نوع التقرير: Scenario summary
  3. في Result cells: حدد خلايا النتائج (مثلاً الربح B5)
  4. اضغط OK - Excel هيعمل شيت جديد فيه تقرير المقارنة!

عرض سيناريو معين

في نافذة Scenario Manager، اختار أي سيناريو واضغط Show. Excel هيغير القيم في الشيت للقيم بتاعة السيناريو ده. كده تقدر تشوف تأثيره على كل المعادلات والجداول.

متى تستخدم Scenario Manager؟ لما يكون عندك نموذج مالي أو خطة عمل وعايز تقارن بين سيناريوهات مختلفة. مثلاً: خطة مبيعات متفائلة vs متشائمة، أو تأثير تغيير أسعار المواد الخام على الأرباح.
"القرار الذكي مش إنك تختار الأفضل بس، إنك تعرف كل الاحتمالات وتكون مستعد لكلها. Scenario Manager بيديك القدرة دي."
تدريب عملي

تمارين

حاول تحل التمارين دي لوحدك الأول. لو محتاج مساعدة، افتح التلميح. ولو عايز تشوف الحل الكامل، افتح الحل.

تمرين 1: تسجيل Macro للتنسيق

سهل

سجل Macro اسمه FormatTable بيقوم بالآتي على الصف الأول: Bold + لون خلفية أزرق غامق + لون خط أبيض + توسيط + حجم خط 12. اربطه باختصار Ctrl+Shift+T.

تلميح: ابدأ التسجيل من View → Macros → Record Macro. حدد الاسم والاختصار. بعدين حدد الصف الأول ونفذ كل خطوات التنسيق بالترتيب. لما تخلص، Stop Recording.
VBA Code (الكود الناتج)
Sub FormatTable()
    Rows(1).Select
    Selection.Font.Bold = True
    Selection.Font.Size = 12
    Selection.Interior.Color = RGB(0, 0, 128)
    Selection.Font.Color = RGB(255, 255, 255)
    Selection.HorizontalAlignment = xlCenter
End Sub

سهل

تلميح: Data → Data Analysis → Descriptive Statistics. حدد Input Range = A1:A31 (مع العنوان). فعّل Labels in first row و Summary statistics. حدد Output Range.
الخطوات:
  1. Data → Data Analysis → Descriptive Statistics → OK

تمرين 3: Goal Seek لنقطة التعادل

متوسط

عندك مشروع: سعر البيع = 80 جنيه، التكلفة المتغيرة = 50 جنيه/وحدة، التكاليف الثابتة = 30,000 جنيه. الربح = (سعر البيع - تكلفة متغيرة) × الكمية - تكاليف ثابتة. استخدم Goal Seek عشان تلاقي الكمية اللي بتحقق نقطة التعادل (ربح = 0).

تلميح: اعمل النموذج: B1=80, B2=50, B3=الكمية (ابدأ بأي رقم), B4=30000, B5=(B1-B2)*B3-B4. بعدين Goal Seek: Set cell=B5, To value=0, By changing=B3.
الحل: الكمية المطلوبة = 1,000 وحدة.
التحقق: (80 - 50) × 1000 - 30,000 = 30,000 - 30,000 = 0

تمرين 6: مقارنة السيناريوهات

متوسط

مشروع كافيه: المدخلات هي (عدد الزبائن يومياً، متوسط الفاتورة، إيجار شهري). اعمل 3 سيناريوهات: Best Case (100 زبون، 50 جنيه، 5000 إيجار)، Worst Case (30 زبون، 30 جنيه، 8000 إيجار)، Most Likely (60 زبون، 40 جنيه، 6000 إيجار). قارن الربح الشهري.

تلميح: اعمل النموذج: الإيرادات = عدد زبائن × متوسط فاتورة × 30 يوم. الربح = الإيرادات - الإيجار - مصاريف أخرى. بعدين Data → What-If → Scenario Manager → أضف 3 سيناريوهات.
النتائج المتوقعة:
  • Best Case: 100 × 50 × 30 - 5000 = 150,000 - 5,000 = 145,000 ربح
  • Most Likely: 60 × 40 × 30 - 6000 = 72,000 - 6,000 = 66,000 ربح
  • Worst Case: 30 × 30 × 30 - 8000 = 27,000 - 8,000 = 19,000 ربح

استخدم Summary لإنشاء تقرير المقارنة في شيت جديد.

تمرين 8: سيناريو تحليل كامل

صعب

أنت مدير مالي لشركة. عندك: إيرادات = سعر × كمية، التكاليف = تكلفة ثابتة + (تكلفة متغيرة × كمية)، الربح = إيرادات - تكاليف. المطلوب:

  • 1) استخدم Goal Seek عشان تلاقي الكمية اللي بتحقق ربح 500,000
  • 2) اعمل Data Table يوضح الربح عند أسعار مختلفة (100-200 بزيادة 20)

تلميح: ابدأ بإنشاء النموذج المالي. بعدين طبق كل أداة واحدة واحدة. Goal Seek للسؤال الأول، Data Table للثاني، Scenario Manager للثالث، وData Analysis ToolPak للرابع.

B2: الكمية = 5000

B4: التكلفة المتغيرة = 80
B5: الإيرادات = B1 * B2 = 750,000
B6: التكاليف = B3 + (B4 * B2) = 600,000
B7: الربح = B5 - B6 = 150,000

   النتيجة: B2 = 10,000 وحدة

2) Data Table: أسعار 100, 120, 140, 160, 180, 200
   Column input cell: B1

ملخص اليوم السادس

اللي اتعلمناه النهاردة

  • Macros بتسجل خطواتك وبتعيد تنفيذها تلقائياً - بتوفر ساعات من الشغل اليدوي
  • تسجيل Macro من View → Macros → Record Macro أو من تاب Developer
  • تشغيل Macro من القائمة (Alt+F8)، اختصار كيبورد، أو زرار مخصص
  • VBA هي اللغة ورا الـ Macros - مش لازم تبقى خبير بس فهم الأساسيات مفيد
  • لازم تحفظ الملف كـ .xlsm عشان الـ Macros متتمسحش
  • Analysis ToolPak بيوفر أدوات إحصائية متقدمة بتتفعل من Add-ins
  • Descriptive Statistics بتديك ملخص إحصائي شامل بضغطة واحدة
  • Histogram بيوريك توزيع البيانات على فئات مختلفة
  • Goal Seek بيلاقي المدخل المطلوب لنتيجة محددة
  • Data Tables بتعرضلك نتائج متعددة لمدخلات مختلفة في جدول واحد
  • Scenario Manager بيحفظ سيناريوهات مختلفة وبيقارن بينها
"الأدوات اللي اتعلمناها النهاردة هي اللي بتفرق بين مستخدم Excel عادي ومحترف. Macros بتوفر وقتك، Data Analysis بتحلل بياناتك، و What-If بتساعدك تاخد قرارات أفضل. ابدأ استخدمهم في شغلك اليومي!"
